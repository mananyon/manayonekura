## 初期構築

米倉さん本人から提供された経歴・実績情報をもとに、1ページのプロフィールを構築。
セクション構成（Hero → Stats → Story → 写真帯 → Activities → Timeline →
Research → Media → Contribution → Links）はこの時点で確定し、以降変えていない。

配色は「和・落ち着き・医療機関っぽくしすぎない」を狙って
生成りベージュ＋朱＋深緑に決定。明朝見出し＋ゴシック本文の組み合わせ。

## 文章のトーン調整

初稿は硬い書き言葉だったが、本人の意向で平易な言い回しに全面的に書き直した。
「寄り添う」→「よりそう」、専門用語を減らす、など。
ターゲットに心の不調を抱えた方が含まれるため、
読んでいて負担にならない文章を優先している。

## フォント: 埋め込み → CDN

当初、日本語フォントをbase64で埋め込んでいたため、公開用ファイルが **17MB** あった。
読み込みに数分かかる状態。
Google Fonts のCDN読み込みに切り替えて **1.2MB** まで削減、
表示は数秒に短縮された。

→ この経緯があるので、フォントの再埋め込みはしないこと。

## ロゴの配置

3事業のロゴ画像（ここちはり / ここちめいど / 鍼灸院）を、
Activitiesの各カードとフッターのリンクカードに中央寄せで配置。

ロゴはJPEG（白背景）のため、カード背景との境界に白フチが出る問題があった。
`mix-blend-mode: multiply` を当てて解消。
根本解決は透過PNGへの差し替え（未対応）。

## カード下端の揃え

Activitiesの3カードで本文の行数が違い、
箇条書きリストの開始位置がバラバラで見た目が崩れていた。

カードを `display: flex; flex-direction: column` にし、
リストに `margin: auto 0 0 0` を当てて下端に押し付ける形で解決。
→ 本文の長さが変わってもリストの位置は揃う。

## 静的HTMLへの書き出し（2026-09-03）

デザインツールの Design Component 形式から、
依存なしの静的HTMLに変換して GitHub Pages 用リポジトリに移行。

変換で行ったこと:

- テンプレート変数3つ（`accent` / `accent2` / `tagline`）を実値に展開
- `style-hover="..."` 属性 12箇所を `.hv1`〜`.hv12` の
  `:hover` CSSルールに変換
- ランタイム（`support.js` / `image-slot.js`）への依存を削除
- `<head>` に title / description / OGP を追加（元にはなかった）
- `a` / `a:hover` のデフォルト色を定義

見た目は変換前と同一。以降の編集は `index.html` に直接行う。
