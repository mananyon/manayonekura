# APNET 講演スライド

`APNET-keicho-60min.pptx` — **全59枚** / 16:9 / 全スライドに発表者ノート（時間配分つき）。
構成の意図とスライド一覧は `docs/APNET-LECTURE-60min.md` を参照。

## 本番前にやること（4つ）

### 1. QRコードを貼る（2か所）
点線の枠が2つあります。枠を削除して、公式LINEのQR画像を配置してください。

| 枚 | 場所 | 用途 |
|---|---|---|
| 46 | 右下・小さめ | 「先に撮っておきたい方はどうぞ」 |
| 59 | 右半分・大きく | 本番のCTA。**ここが本体** |

59枚目には短縮URLも入れてください（口頭で読み上げる用）。

### 2. 10秒カウントダウンを自動送りにする（31〜40枚目）
1. スライド一覧で **31〜40枚目の10枚を選択**
2. 「画面切り替え」タブ →「自動的に切り替え」に **00:01** と入力
3. 「クリック時」のチェックを**外す**

これで10秒が自動で進みます。数字を画面に出しておくことで、
アーカイブ視聴者に「配信事故」と誤解されるのを防げます。

### 3. 音声を録っておく（42〜43枚目で使用）
パターンA（聴けていない応対）／パターンB（傾聴の応対）を各60秒。
相方はサロンメンバーに依頼。音量を揃えること。
Zoomの画面共有で「**コンピューターの音声を共有**」をONにする設定は、リハで必ずテスト。

### 4. 依頼しておくもの
- **サロンメンバー** … ①29・45枚目のチャットで口火を切る役 ②上記の患者役
- **共同ホスト** … ①チャットへのリンク投下 ②45枚目の投稿を3つコピー ③タイムキープ

- **51枚目の症例**は類型として提示しています。個別事例を語る場合は個人が特定されない形で

## デザイン

`docs/HANDOFF.md` のトークンをそのまま使用しています。

| 用途 | 色 |
|---|---|
| 背景（生成り） | `ECE3D4` |
| カード | `FCFAF4` |
| 濃色スライド | `2B2620` |
| 朱色（アクセント） | `9C5446` |
| 深緑（アクセント） | `5E7060` |

見出しは明朝、本文はゴシック。青系は不使用。モチーフは「円」。

**フォント**は見出し=游明朝／本文=游ゴシック。Windows・Mac の Office 双方に入っています。
表示が崩れる場合は、PowerPoint の「フォントの置換」でヒラギノやメイリオに一括変更してください。

## 作り直すとき

```bash
npm install pptxgenjs
node build.js APNET-keicho-60min.pptx
```

`build.js` が生成元です。

- **縦位置は自動リフロー**されるので、座標は「相対的な並び」だけ気にすれば大丈夫です
- **各スライドの時刻は `TIMINGS`（build.js 末尾）で一元管理**しています。
  スライドを増減したら、ここだけ直せばノートの時間表記が全部揃います
