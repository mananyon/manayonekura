# APNET 講演スライド

`APNET-keicho-60min.pptx` — **全63枚** / 16:9 / 全スライドに発表者ノート（時間配分つき）。
構成の意図とスライド一覧は `docs/APNET-LECTURE-60min.md` を参照。

## 本番前にやること（4つ）

### 1. QRコードを貼る（2か所）
点線の枠が2つあります。枠を削除して、公式LINEのQR画像を配置してください。

| 枚 | 場所 | 用途 |
|---|---|---|
| 46 | 右下・小さめ | 「先に撮っておきたい方はどうぞ」 |
| 63 | 右半分・大きく | 本番のCTA。**ここが本体** |

63枚目には短縮URLも入れてください（口頭で読み上げる用）。

### 2. 10秒カウントダウンを自動送りにする（31〜40枚目）
1. スライド一覧で **31〜40枚目の10枚を選択**
2. 「画面切り替え」タブ →「自動的に切り替え」に **00:01** と入力
3. 「クリック時」のチェックを**外す**

これで10秒が自動で進みます。数字を画面に出しておくことで、
アーカイブ視聴者に「配信事故」と誤解されるのを防げます。

### 3. 音声を録っておく（42〜43枚目で使用）
パターンA（聴けていない応対）／パターンB（傾聴の応対）を各60秒。
相方はサロンメンバーに依頼。音量を揃えること。
Zoomの画面共有で「**コンピューターの音声を共有**」をONにする設定は、リハで必ずテスト。

### 4. 依頼しておくもの
- **サロンメンバー** … ①29・45枚目のチャットで口火を切る役 ②上記の患者役
- **共同ホスト** … ①チャットへのリンク投下 ②45枚目の投稿を3つコピー ③タイムキープ

## 確認しておきたいこと

- **4枚目（当事者経験）は、話すかどうかご自身で決めてください。** 削除しても講演は成立します
- **17枚目の実態調査の数値**は第4報の記載どおりです。発表前に最新値をご確認ください
- **12枚目**は日本いたみ財団の研修会資料からの要約引用です。図表をそのまま使う場合は事前に許諾を
- **51〜54枚目の症例報告**：共同演者のお名前と学会名・年をご確認ください
- **55枚目の変化の4類型**は類型として提示しています。個別事例を語る場合は個人が特定されない形で

## デザイン

色はオンラインサロン「**ここちめいど**」のロゴから取っています。
（ロゴ実測：深緑 `#1D8A53` ／ ミント `#34D39B` ／ ピンク `#F15C9E`）

| 用途 | 色 | メモ |
|---|---|---|
| 明るいスライドの地 | `F0FAF5` | ミントをごく薄く効かせた白 |
| カード | `FFFFFF` | |
| 濃色スライド／本文 | `123C2A` | ロゴの深緑を暗く寄せた色 |
| 主アクセント（深緑） | `17784A` | どのサイズの文字にも使える |
| 副アクセント（ピンク） | `C92A78` | 小さい文字でも読めるよう濃いめ |
| ロゴのピンク | `F15C9E` | 濃色スライドの見せ場だけ |
| ミント | `34D39B` | 面で使う。**白文字は乗せない**（文字は `123C2A`） |

見出しは明朝、本文はゴシック。青系は不使用。モチーフは「円」。

**ピンクは講演全体で5か所だけ**に絞っています（ロゴのハートが1枚だけなのと同じ考え方）。
「悪いのは、あなたではありません」「ひとりでやると、壊れます」「13 → 5」
「最初の90秒、遮らない。」「ただ、話を最後まで聴いてもらうことでした。」の5つです。
増やすと効かなくなるので、足すときはどれかを減らしてください。

コントラストは実測しています。ミントは白文字とのコントラストが 1.9 しかないため、
ミントの帯の上の文字は濃緑（`123C2A`）にしてあります。ここは入れ替えないでください。

※ プロフィールサイト（`docs/HANDOFF.md`）は生成りベージュ＋朱＋深緑の別パレットです。
　このスライドだけサロンのロゴ配色を使っています。

**フォント**は見出し=游明朝／本文=游ゴシック。Windows・Mac の Office 双方に入っています。
表示が崩れる場合は、PowerPoint の「フォントの置換」でヒラギノやメイリオに一括変更してください。

## 作り直すとき

```bash
npm install pptxgenjs
node build.js APNET-keicho-60min.pptx
```

`build.js` が生成元です。

- **縦位置は自動リフロー**されるので、座標は「相対的な並び」だけ気にすれば大丈夫です
- **各スライドの時刻は `TIMINGS`（build.js 末尾）で一元管理**しています。
  スライドを増減したら、ここだけ直せばノートの時間表記が全部揃います
