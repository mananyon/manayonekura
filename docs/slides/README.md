# APNET 講演スライド

`APNET-keicho-60min.pptx` — 全53枚 / 16:9 / 全スライドに発表者ノート付き。
構成の意図は `docs/APNET-LECTURE-60min.md` を参照。

## 本番前にやること（5つ）

### 1. QRコードを貼る（2か所）
点線の枠が2つあります。枠を削除して、公式LINEのQR画像を配置してください。

| 枚 | 場所 | 用途 |
|---|---|---|
| 40 | 右下・小さめ | 「先に撮っておきたい方はどうぞ」 |
| 53 | 右半分・大きく | 本番のCTA。**ここが本体** |

53枚目には短縮URLも入れてください（口頭で読み上げる用）。

### 2. 10秒カウントダウンを自動送りにする（25〜34枚目）
1. スライド一覧で **25〜34枚目の10枚を選択**
2. 「画面切り替え」タブ →「自動的に切り替え」に **00:01** と入力
3. 「クリック時」のチェックを**外す**

これで10秒が自動で進みます。数字を画面に出しておくことで、
アーカイブ視聴者に「配信事故」と誤解されるのを防げます。

### 3. 差し替えが必要な枠（2か所）
- **10枚目** — 学会発表（第3報・第4報）の図。数字はこちらでは入れていません
- **45枚目** — ご自身の症例。掲載許可の確認を

### 4. 音声を録っておく（36〜37枚目で使用）
パターンA（聴けていない応対）／パターンB（傾聴の応対）を各60秒。
相方はサロンメンバーに依頼。音量を揃えること。
Zoomの画面共有で「**コンピューターの音声を共有**」をONにする設定は、リハで必ずテスト。

### 5. 依頼しておくもの
- **サロンメンバー** … ①23・39枚目のチャットで口火を切る役 ②上記の患者役
- **共同ホスト** … ①チャットへのリンク投下 ②39枚目の投稿を3つコピー ③タイムキープ

## デザイン

`docs/HANDOFF.md` のトークンをそのまま使用しています。

| 用途 | 色 |
|---|---|
| 背景（生成り） | `ECE3D4` |
| カード | `FCFAF4` |
| 濃色スライド | `2B2620` |
| 朱色（アクセント） | `9C5446` |
| 深緑（アクセント） | `5E7060` |

見出しは明朝、本文はゴシック。青系は不使用。モチーフは「円」。

**フォント**は見出し=游明朝／本文=游ゴシック。Windows・Mac の Office 双方に入っています。
表示が崩れる場合は、PowerPoint の「フォントの置換」でヒラギノやメイリオに一括変更してください。

## 作り直すとき

```bash
npm install pptxgenjs
node build.js APNET-keicho-60min.pptx
```

`build.js` が生成元です。縦位置は自動リフローされる（各スライドの内容量に応じて
上下に伸縮する）ので、座標は「相対的な並び」だけ気にすれば大丈夫です。
