このフォルダに2本のスライドが入っています。**どちらを本番で使うかはご確認ください。**

| ファイル | 枚数 | 性格 | 手引き |
|---|---|---|---|
| `APNET-keicho-60min.pptx` | 63枚 | 講演構成を練り込んだ版。症例報告（PHQ-9の推移）と体験ワーク4種を含む | `README.md` |
| `keicho-seminar.pptx` | 47枚 | セミナー版。ピンクの象のワーク、8つの技法、**LINE登録／無料セミナーへの導線つき** | `README-seminar.md` |

## 中身のちがい

**63枚版**は「傾聴とは何か」を積み上げる講演型です。医師からの評価 → 自問 → テーマ宣言で入り、
四診・慢性疼痛診療・地域の4つの役割で論拠を固め、体験ワーク（ソロ想起／10秒の沈黙／聴き比べ／
チャット一斉投下）を山場に置いています。締めは公式LINEへの問合せ。

**47枚版**はセミナー型です。「こんなことありませんか」4つで入り、
距離感の話（依存させ切らない／私の失敗）と、傾聴の8つの技法・自動思考・ピンクの象のワークが中心。
締めがサロン募集（2027年7月スタート予定）と無料セミナーの案内になっています。

## 共通の準備

- 公式LINEのQRコード（各資料の最終スライド。点線枠を差し替え）
- タイマー（PowerPointは自動カウントできません。時計かスマホで）
- ファイルの再生成：

```bash
npm install pptxgenjs
node build.js APNET-keicho-60min.pptx          # 63枚版
node build-seminar.js keicho-seminar.pptx      # 47枚版
```
