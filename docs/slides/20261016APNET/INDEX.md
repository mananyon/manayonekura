# APNET（2026.10.16）資料一式

## おすすめ：`APNET本番版.pptx`（59枚・60分）

セミナー版47枚をベースに、講演版から**症例報告**と**明日からできる3つの型**を移植し、
全体を「**聴けると、何ができるか**」という1本の背骨で通したものです。

| ファイル | 枚数 | 性格 |
|---|---|---|
| **`APNET本番版.pptx`** | **59** | **本番用** |
| `keicho-seminar.pptx` | 47 | セミナー版（統合元） |
| `APNET-keicho-60min.pptx` | 63 | 講演版（統合元） |

## 背骨：聴けると、4つのことができる

9枚目で地図を渡し、章ラベルで現在地を示し、50枚目で実例として回収します。

| | できること | 本編での担当 |
|---|---|---|
| ① | 情報が集まる | 10–11枚目（2種類の情報／四診の「問」） |
| ② | 危険に気づける | 12–13枚目（レビー小体型認知症の事例／ご高診後の診断名） |
| ③ | つなげる | 16–23枚目（0.4%／依存先を増やす／連携先／事例2つ） |
| ④ | 自分が潰れない | 24–29枚目（長く続く患者さん／私の失敗／距離のサイン） |

**50枚目「聴けたから、できたこと」** が結論スライドです。
証が立った／見落とさなかった／治療目標が分かった／制度につなげた／薬をやめずに済んだ／
入院を回避できた——6つとも今日の中で出てきた実例で、番号は①〜④に対応しています。
締めは「**どれも、聴かなければ できませんでした。だから、聴くんです。**」

## 言葉づかいについて

**「いい／良い」という評価語は、スライド本文から外しています。** 評価もジャッジだからです。
「全部知らなくて大丈夫」「日常が動きはじめる方も」のように、descriptive な言い方にそろえました。

残してあるのは、意図的なものだけです。

- 2枚目「患者さんに『良くなった』と言われたい」… 28枚目で問い直す対象そのもの
- 48枚目「大丈夫、すぐ良くなりますよ」… 言ってしまいがちな例として提示
