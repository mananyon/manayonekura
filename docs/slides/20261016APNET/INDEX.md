# APNET（2026.10.16）資料一式

## おすすめ：`APNET本番版.pptx`（57枚・60分）

セミナー版47枚をベースに、講演版から**症例報告4枚**と**明日からできる3つの型4枚**を
移植したものです。「精神科領域の患者を診たい鍼灸師に、明日から傾聴をやってみようと
思ってもらう」という目的には、これが一番効きます。

| ファイル | 枚数 | 性格 |
|---|---|---|
| **`APNET本番版.pptx`** | **57** | **本番用。下の2本を統合したもの** |
| `keicho-seminar.pptx` | 47 | セミナー版（統合元。症例と型がない） |
| `APNET-keicho-60min.pptx` | 63 | 講演版（統合元。距離感とピンクの象がない） |

手引き：本番版は `README-seminar.md`（構成はほぼ共通）／講演版は `README.md`

## 本番版の流れ

| 時間 | ブロック |
|---|---|
| 0–4:30 | こんなことありませんか4つ →「答えはあります」→ 自己紹介 |
| 4:30–15:30 | 人は分かり合えない → 聞くしかない → **傾聴で2種類の情報が集まる**（四診／レッドフラッグ／実費の強み） |
| 15:30–25:10 | **鍼灸院にいる時間は0.4%** → 抱えない、つなぐ（依存先を増やす）→ 連携先・事例2つ → 薬は止めない |
| 25:10–32:30 | 「聴いてもらえなかった」患者 → **私の失敗** → 距離が近すぎるサイン → 自己理解 |
| 32:30–37:40 | **症例報告**（PHQ-9 13→5・傾聴の4段階・入院回避） |
| 37:40–43:10 | 8つの技法 → **感情を、追い越さない** |
| 43:10–52:05 | 自動思考 → **ピンクの象のワーク** → 「気にしないで」と言っていませんか → ジャッジ |
| 52:05–55:50 | **明日からできる3つの型** |
| 55:50–60:00 | まとめ → サロン案内 → LINE登録・無料セミナー |
| 付録 | 社会再適応評価尺度（時間があれば／配布資料として） |

## 狙いの置きどころ

- **「鍼を打つだけじゃない」** … 15枚目「鍼灸院にいる時間は0.4%」と18枚目「自立とは依存先を増やすこと」。この2枚が背骨
- **「傾聴の意義」** … 31枚目「傾聴にも、順番があります」。傾聴は才能ではなく段階のある技術だ、という証明
- **「明日からやってみよう」** … 49〜52枚目の3つの型。最後は1つに絞って渡す
- **やりがちな失敗の2枚** … 37枚目「感情を、追い越さない」と47枚目「『気にしないで』と言っていませんか」。
  どちらも善意でやってしまうこと。責めない口調で、「私も言っていました」と添えて話す
