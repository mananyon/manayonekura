# 傾聴セミナー資料（サロン募集用）

`keicho-seminar.pptx` — **全47枚** / 16:9 / 全スライドに発表者ノート（時間配分つき）。
60分想定。ワークを丁寧にやると90分になります。

既存の `APNET-keicho-60min.pptx`（APNET講演用・全63枚）とは**別物**です。
こちらは「LINE登録 → 無料セミナー → サロン（2027年7月）」への導線を持つ集客用。

## 構成

| 時間 | ブロック | 役割 |
|---|---|---|
| 0–5分 | こんなことありませんか → 答えはあります → 自己紹介 | つかみ |
| 5–18分 | 人は分かり合えない → 聞くしかない → 傾聴で2種類の情報が集まる | なぜ傾聴か |
| 18–30分 | 院にいる時間は0.4% → 抱えない、つなぐ → 連携先 → 事例2つ → 薬は止めない | 治すだけが全てではない |
| 30–39分 | 「聴いてもらえなかった」患者 → 私の失敗 → 距離が近すぎるサイン → 自己理解 | 距離感 |
| 39–56分 | 8つの技法 → 自動思考 → **ピンクの象のワーク** → 社会再適応評価尺度 | やり方 |
| 56–60分 | まとめ → サロン案内 → LINE登録・無料セミナー | クロージング |

### 元資料との対応
- `01-02MTG.pptx` … 冒頭の「こんなことありませんか」4つ／前提「人は分かり合えない」／自己理解／薬は止めない
- `06_*.pptx` … 8つの技法／自動思考とジャッジ／ピンクの象のワーク／社会再適応評価尺度
- 学会発表（地域連携）… 4つの役割／レッドフラッグ事例／連携先／傷病手当金・服薬アドヒアランスの事例

## 本番前にやること

### 1. QRコードを貼る（47枚目）
点線の枠を削除して、公式LINEのQR画像を配置。短縮URLも入れてください（口頭で読み上げる用）。

### 2. 数字と日付の確認
- **46枚目「2027年7月スタート予定」** … 年月が違っていたら直してください。「予定」であることを口頭でも添えて
- **37枚目の答え**（象の挙げていた足）… ノートには「向かって右」と書いていますが、本番前にイラストでご確認ください

### 3. タイマーの用意
- 36枚目：10秒（象を見せる）
- 39枚目：3分（目を閉じる）

PowerPointは自動カウントダウンできないので、時計かスマホで計測してください。

### 4. 3分のワークは、削らない
このセミナーの山場です。理屈で説明するより体験させたほうが速く、
「勝手に浮かんでくる＝自動思考」が一発で腑に落ちます。

## 設計の意図

- **売り込みは最後の3枚だけ。** 46枚目でまず「いまは募集していません」と言うのが肝です。
  売り込みに聞こえなくなり、かえって問合せが増えます
- **冒頭の4つのあるあるは、後半で回収**します。
  ④「施術後に疲れてしまう」→ 26枚目「距離が近すぎる、3つのサイン」
- **距離感の話（23〜28枚目）が、このセミナーの独自性**です。
  「長く通ってもらう」を否定しているのではなく、依存先がひとつきりになるのが危ない、という話。
  ここは誤解されやすいので丁寧に
