# APNET 講演 60分 スライド構成案
**演題（案）：経絡に触れ、こころに耳を傾ける ― 鍼灸師のための傾聴トレーニング**
米倉まな / 想定聴衆：鍼灸師（開業・勤務・学生）

---

## 0. この講演のゴール設計

| 種類 | ゴール |
|---|---|
| 表のゴール | 「傾聴は才能ではなく訓練である」と伝える |
| 裏のゴール | 「自分ひとりでは身につかない → 伴走してくれる人が欲しい」と思ってもらう |
| 行動ゴール | 講演後〜3日以内に公式LINEへの問合せが増える |

### 問合せが生まれる心理の順番（この順でスライドを積む）
1. **自覚** ―「自分は聴けているつもりだった」と気づく
2. **希望** ―「型があるなら自分にもできそう」と思う
3. **限界** ―「でも独学は無理だし、一人だと壊れる」と分かる
4. **一歩** ―「今日ここで、ひとつだけやればいい」が明確になる

売り込みは最後の3分だけ。ただし全編に「私はこう伴走してきた」という証拠を散らす。
**"教える人"として立たない。"傾聴で臨床が変わった同業者"として立つ。**

### スルーライン（全編を貫く一行）
> 経絡に触れ、こころに耳を傾ける。

冒頭で置き、最後に同じ言葉で返す。これだけで講演が一本の線になります。

## 2. スライド構成（1枚ずつ）

### ■ ブロックA　オープニング（0–3分／3枚）

**S1｜タイトル**
- 「経絡に触れ、こころに耳を傾ける ― 鍼灸師のための傾聴トレーニング」
- ビジュアル：施術の手元 or 院の写真1枚。文字は少なく。

**S2｜問いかけ（最重要スライド）**
- 大きく一行だけ：**「最後に患者さんの話を、最後まで遮らずに聴いたのはいつですか？」**
- 話す：「今日は答えなくていいです。ただ、思い出しながら聞いてください」
- 狙い：講演の主語を"私"から"あなた"に移す。ここで刺さらないと最後のCTAが効きません。

**S3｜11秒**
- 数字を1つだけ大きく：**11秒**
- 医師は患者が話し始めてから中央値11秒で話を遮る（Singh Ospina et al., 2019 / 先行研究 Beckman & Frankel 1984 では18秒）
- 話す：「これは医師を対象にした研究です。では、私たち鍼灸師は？ ―― 私たちには**40分**あります」
- 狙い：問題提起と同時に「鍼灸師は聴ける職種」という誇りを立てる。

### ■ ブロックB　自己紹介（3–8分／3枚）

> 実績の羅列はNG。**「昔の自分＝今日の聴衆」**として語ると、後半の提案が説教にならない。

**S4｜私は聴けていませんでした**
- 開業初期の話。「主訴を聞き出す」ことに必死で、患者さんの話を"情報収集"として処理していた頃
- 具体的なエピソードを1つだけ（涙をこぼした患者さんに、次の質問をかぶせてしまった等）
- 狙い：自己開示で信頼の橋を架ける。ここが弱いと全部が"上手い人の話"になります。

**S5｜転機**
- 傾聴に出会って何が変わったか。**症状の話ではなく、通院の続き方・紹介の増え方・自分の消耗度**で語る
- 数字：のべ臨床患者数20,000人+ / 開業11年目

**S6｜今やっていること（3事業）**
- 臨床：はりきゅう処ここちめいど（四日市／2026年夏 町田院）
- 学び：オンラインサロン ここちめいど（2020年〜／傾聴を学ぶ鍼灸師コミュニティ）
- 育成：ここちはり（2025年11月〜）
- 研究：全日本鍼灸学会（うつ・不安症状の実態調査 第3・4報）／武蔵野大学大学院 人間学 修士／2026.6 日本精神神経学会シンポジスト
- **20秒で流す。**「詳しくは最後に」と言って進む（＝最後まで残る理由をつくる）

### ■ ブロックC　なぜ、鍼灸師に傾聴か（8–18分／6枚）

**S7｜鍼灸師は"最強の聴き手"になれる**
- 40〜60分の密室 / 身体に触れている / 定期的に会い続ける / 白衣でも医師でもない距離感
- 「こんな条件が揃っている職種は他にありません」

**S8｜けれど、こうなっていないか**
- あるある3つ（会場が笑って頷くやつ）
  - 問診票を見ながら「他には？」
  - 話が長い患者さんに、内心あせる
  - 沈黙が怖くて、つい説明を始める
- 狙い：**自覚**。ここで全員を自分ごとにする。

**S9｜"聴けない"のは性格ではなく構造**
- 時間の圧・保険/自費の圧・「治さねば」という職業的責任感
- 「悪いのはあなたではない。習っていないだけです」＝ 逃げ道を用意する（責めると問合せは来ない）

**S10｜患者さんが本当に困っていること**
- 学会発表データ（鍼灸院におけるうつ・不安症状を有する患者の実態調査）から1〜2枚の図
- 「身体の主訴で来た人の背後に、どれだけ心の話があるか」を自分の研究で示す
- 狙い：**カリスマの直感ではなくエビデンスで話す人**というポジション取り。ここがメンター依頼の質を上げます。

**S11｜聴くことは、治療の一部**
- 治療同盟／ノセボ・プラセボ／安心が自律神経に与える影響
- 「傾聴は施術の前段階ではなく、施術そのもの」

**S12｜スルーライン再掲**
- 「経絡に触れ、こころに耳を傾ける。これが鍼灸のチカラだと思っています」
- 一拍おいて次へ。

### ■ ブロックD　傾聴の正体（18–28分／6枚）

**S13｜傾聴の3つの誤解**
- ❌ 黙って聞くこと　❌ 共感して同意すること　❌ アドバイスを我慢すること
- 「全部ちがいます」

**S14｜傾聴とは何か（定義）**
- ロジャーズの3条件を鍼灸師の言葉に翻訳して提示
  1. **自己一致** → 術者が整っていないと、鍼はぶれる
  2. **無条件の肯定的関心** → 証を立てる前に、まず在るものに触れる
  3. **共感的理解** → 相手の世界の"内側"から聴く

**S15｜原則1：沈黙を待つ**
- 「置鍼の待ち時間、あなたは待てますよね。あれと同じです」
- 沈黙3秒ルール。相手が言い終わってから、心の中で1・2・3

**S16｜原則2：解釈を置く**
- 「頭に浮かんだ"証"を、いったん脇に置く」
- 早すぎる解釈が、患者の話を止める

**S17｜原則3：自分を整える**
- 聴く側のコンディションが全て。疲れている日は聴けない
- 「だから傾聴は"訓練"なんです。知識ではなく状態だから」

**S18｜つなぎ：では、やってみましょう**
- 「ここまでは知識です。知識では1ミリも変わりません」

### ■ ブロックE　体験ワーク／オンライン・カメラオフ版（28–40分／6枚）★山場

> **前提：カメラオフ・ブレイクアウトなし・チャットのみ でも成立する構成にしています。**
> カメラオフでペアワークをやると「反応が見えない → 不安 → 誰も話さない」で崩れます。
> 顔が見えない環境では、**①自分の内側を見る ②聴こえるものに集中する ③文字で出す** の3つが効きます。
> そしてこの講演では、それが**むしろ本題に直結します**（声だけで聴くのは、いのちの電話と同じ条件）。

**S19｜リフレーム：今日は、顔が見えないほうが好都合です**
- 「今日はみなさんカメラオフですね。実は、傾聴の練習には**この方が向いています**」
- 「表情という情報がない分、声そのものを聴くしかない。電話相談と同じ条件です」
- 狙い：制約を"わざとそうした"に変える。ここで場の空気が一段変わります。

**S20｜ワーク①：思い出せますか（ソロ／3分）★これが一番効きます**
- 指示：「**紙とペンを用意してください。** 直近に施術した患者さんを1人思い浮かべてください」
- 「その方が言った**言葉そのもの**を、3つ書き出してください。要約ではなく、口にした言葉のまま。90秒です」
- 90秒タイマー（スライドに大きく表示）
- 種明かし：「症状は書けたはずです。でも**"言葉"は書けましたか？**」
- 「私たちは、聴いたつもりで**情報に変換して**います。人の言葉としては、残っていない」
- 狙い：カメラオフでも100%全員が当事者になる唯一のワーク。**自覚のピーク**。
- ※チャットに「何個書けましたか？ 数字だけ送ってください」→ 数字だけなら心理的ハードルが低く、一気に流れます

**S21｜ワーク②：10秒の沈黙（全員／1分半）**
- 「今から10秒、私は何も話しません。みなさんも何もしないでください」
- スライドは真っ黒 or カウントダウンのみ。**本当に10秒黙る**（登壇者にとってはかなり長い）
- 明けてから：「どうでしたか。落ち着かなかった人、チャットに『1』を」
- 「この居心地の悪さが、あなたが患者さんの沈黙をつぶしている理由です」
- 狙い：カメラオフ・ミュートのままでも身体感覚が動く数少ないワーク。

**S22｜ワーク③：聴き比べ（実演／5分）**
- **同じ患者さんの同じ一言**に、2通りの応対を聴かせる。**音声だけで十分**（カメラオフだからこそ声に集中できる）
- 患者の発話（共通）：「最近、夜眠れなくて……仕事も、まあ、いろいろあって」
  - **パターンA（聴けていない）**：「そうですか、不眠ですね。何時ごろお休みですか？ 肩こりはあります？」
  - **パターンB（傾聴）**：「……いろいろ、あって」＋沈黙 → 患者が自分から続きを話し出す
- 「Aで取れた情報と、Bで取れた情報。**どちらが多かったですか**」
- 「傾聴は、優しさの話ではありません。**情報量の話**です」
- 実装：**事前に60秒×2本を録音しておく**（生の実演は回線・間の取り方でぶれる）。相方はサロンメンバーに依頼

**S23｜チャット一斉投下（2分半）**
- 問い：「**あなたが最後に"ちゃんと聴いてもらえた"のは、いつ、誰にですか？**」
- 「打ち終わっても送らないでください。私が3・2・1と数えたら、**全員同時に送信**します」
- カウントダウン → チャットが一気に流れる（この"滝"の体験自体が場を温めます）
- 3つほど読み上げてコメント。**ここで出た言葉が、この講演で一番強いコピーになります**
- 狙い：一斉送信にすることで「自分だけ書く」恥ずかしさを消す。カメラオフの匿名性がプラスに働く数少ない場面。

**S24｜たった13分で、これです**
- 「今のは全部合わせて13分です。あなたの施術は40分ある」
- 狙い：**希望**のピーク。ここまでで聴衆は「やってみたい」状態。
- ※QRを一瞬だけ出す →「あとで出しますが、先に撮っておきたい方はどうぞ」

#### ブレイクアウトルームが使える場合の差し替え（任意）

主催がブレイクアウトを許可し、**参加者が音声を出せる**なら、S22の後に3分×2のペアワークを入れられます。
その場合も**カメラは全員オフのまま**にしてください（「顔を出さなくていい」と明言するほど参加率が上がります）。

- 2人1組・お題「最近、ちょっとうれしかったこと」（ネガティブなお題は安全上NG）
- 聴き手のルールは1つ：**質問もアドバイスも禁止。相づちだけ**
- 3分で強制的に部屋を戻す（延長しない）
- ただし**離脱リスクが上がる**ので、参加者が初対面中心・50名超なら**やらない方が安全**です

### ■ ブロックF　臨床への実装（40–50分／6枚）

**S25｜明日からできる3つの型**
- 一覧で先に見せる（①最初の90秒 ②反復＋一拍 ③閉じない締め）

**S26｜型①：最初の90秒は遮らない**
- 問診票を見ない。ペンを置く。「今日はどうされましたか？」の後、90秒何も足さない
- 「90秒です。1日10人で15分。それだけです」

**S27｜型②：反復＋一拍**
- 相手の言葉を、相手の言葉のまま返す。「ずっと、しんどかったんですね」
- 要約もリフレーミングもしない。言い換えた瞬間、それは自分の言葉になる

**S28｜型③：施術後を閉じない**
- ❌「軽くなりましたか？」→ ⭕「いま、どんな感じですか？」
- 閉じた質問は情報を閉じる

**S29｜症例：こう変わった**
- 実例1つ（個人情報は抽象化）。**症状の改善より、関係と継続の変化**を語る
- 可能なら症例データベース（ケアクル／東京有明医療大学／玉川大学との共同研究）に触れる

**S30｜私の失敗**
- 聴きすぎて自分が消耗した時期。カウンセラーになろうとして施術がぶれた話
- 「傾聴には、自分を守る技術がセットで必要です」
- 狙い：**限界**の提示。ここが次ブロックへの唯一の橋。ここを飛ばすと最後がただの宣伝になります。

### ■ ブロックG　続けるための場（50–56分／4枚）

**S31｜傾聴は、独学で伸びない理由**
1. 自分の聴き方は、自分では見えない（フィードバックが要る）
2. 一人だと"聴きっぱなし"で消耗する（受け止めてもらう側が要る）
3. 3週間で元に戻る（続ける仕組みが要る）
- 「才能の話ではありません。**環境の話**です」

**S32｜だから、場をつくりました**
- オンラインサロン ここちめいど（2020年〜）：傾聴を学ぶ鍼灸師コミュニティ
- 5年間で学会発表体制を構築（2026 全日本鍼灸学会で発表）
- 「学ぶだけの場ではなく、**書く・出す・立つ**まで伴走する場です」

**S33｜メンバーに起きたこと**
- 学会デビュー／書籍出版／院の変化。**主語をメンバーにする**（自分の実績にしない）
- 顔写真や声を1〜2つ（許可済みのもの）
- 狙い：「あの人にできたなら」という自己投影

**S34｜ここちはり（育成・コンサル）**
- 感情・心・身体・技術の4軸／症例データベースの公開・運用
- 「1対1で伴走してほしい方には、こちらがあります」
- **ここで初めて"メンター"という言葉を出す**

### ■ ブロックH　クロージング（56–60分／3枚）

**S35｜今日、ひとつだけ持ち帰るなら**
- 「**最初の90秒、遮らない。** これだけです。明日の1人目からできます」
- 持ち帰りを1つに絞る。3つ渡すと0個になります。

**S36｜スルーラインで閉じる**
- 「経絡に触れ、こころに耳を傾ける。それが、私たちの持っているチカラです」
- 一拍。ここで拍手が来る設計。

**S37｜CTA（入口は1つだけ）**
- 大きなQRコード **1つ**（公式LINE推奨）＋「本日のスライドをお送りします」
- 壇上から言葉を渡す ↓
  > 「今日の話で、"うちの院ではどうしたらいいんだろう" と思った方。
  > その質問、そのままLINEに送ってください。私が読みます。」
- **30秒黙ってQRを映す時間をとる**（読み取り待ち。ここを急ぐと激減します）

## 3. 問合せを増やすための7つの仕掛け

1. **入口は1つ。** サロン／ここちはり／院のLINEを3つ並べない。迷った人は動きません。公式LINE1本に集約し、その先で分岐。
2. **スライド配布を理由にする。** 「PDFを送ります」は、連絡先を渡す最も自然な口実。
3. **問合せの文面を壇上から与える。**「"うちの院ではどうしたら"と送ってください」＝ 何を書けばいいか分からない不安を消す。
4. **オンラインはQRより"チャットにリンク"が強い。** その場でタップできる＝対面より有利。QRも併記（スマホ視聴者用）し、**30秒映して黙る**。
   - チャット投稿は**自分で打たず、事前にメモ帳へ用意してコピペ**（登壇中にタイプミスすると致命的）
   - 可能なら共同ホストに「S24とS37でこの文面を貼って」と依頼しておく
5. **QRはS24（ワーク直後の感情ピーク）にも一瞬出す。** 「あとで出しますが、先に撮っておきたい方はどうぞ」
6. **Q&Aタイムこそ営業。** 質問には即答せず、まず「その患者さん、なんて仰ってました？」と**聴き返す**。傾聴の実演が最強の営業です。オンラインは全員がその様子を見ています。
7. **48時間以内にフォロー。** 登録者へ「スライドPDF＋今日のワークの再現手順」を送る。ここで初めて次の案内を1行だけ添える。
8. **アーカイブ視聴者を取りこぼさない。** 録画配信があるなら、S37のQR/リンクは**画面に固定で30秒**（後から見る人はチャットが読めません）。

## 4. 想定Q&A

| 質問 | 答えの方向 |
|---|---|
| 保険診療で時間がなくても可能ですか | 90秒だけ。時間ではなく最初の使い方の問題 |
| 話が終わらない患者さんはどうする | 傾聴は無制限に聴くことではない。枠を先に伝えるのも傾聴（「今日は10分、じっくり伺います」） |
| 心の話を聴いて悪化させないか | 聴くことと介入は別。境界線と紹介先を持つ（連携先の話へ） |
| 資格は必要ですか | 不要。ただしフィードバックをもらえる環境は必要 |
| 男性鍼灸師でも大丈夫か | 傾聴に性別は関係ない。むしろ武器になる |
