# 引き継ぎ資料 — 米倉まな プロフィールサイト

作成日: 2026-09-03

## 1. このサイトの目的

メンタル鍼灸師・米倉まなの「実績プロフィール」1ページ。
用途は次の3つを想定している。

- メディア取材・講演依頼を受けたときに送る自己紹介ページ
- 学会・産学連携の相手に活動実績をまとめて見せる
- 施術者育成「ここちはり」に関心を持った鍼灸師への入口

営業用のランディングページではない。CVを取りにいく設計にはしていない
（唯一のCTAはフッターのLINE 2本のみ）。実績を淡々と並べ、
本人の言葉で「なぜこの仕事をしているか」を伝えることを優先している。

## 2. デザインの考え方

**トーン**: 医療機関の清潔感より「和の落ち着き」を優先。
背景は生成りのベージュ（`#ECE3D4`）、見出しは明朝（Noto Serif JP）。
青系は一切使わない。朱色（`#9C5446`）と深緑（`#5E7060`）の2アクセント。

**リズム**: 明るいベージュのセクションが続くなかに、
濃色（`#2B2620`）の帯を2回（Stats / Research）と
フルブリード写真帯を1回（Clinic Night）挟んでいる。
これがページ全体の呼吸になっているので、
セクションを追加するときは「明るい面が3つ以上連続しないか」を意識してほしい。

**余白**: `padding: 88px 56px` が標準セクション。
情報量が多いセクションでも詰めない。詰まって見えるときは要素を減らす。

**文章**: 平易な語彙を意図的に選んでいる。「よりそう」「たしかめる」
「まるごとサポート」など。ターゲットに心の不調を抱えた方が含まれるため、
硬い医療用語や煽り表現を避けている。**ここを "プロっぽく" 直さないこと。**

## 3. 技術構成

- 静的HTML 1ファイル + 画像11点。ビルドなし、JSなし。
- CSSはインラインstyle属性が原則。`<head>` の `<style>` にあるのは
  リセット・メディアクエリ・`:hover` クラス（`.hv1`〜`.hv12`）のみ。
- フォントは Google Fonts をCDN読み込み（Noto Serif JP / Noto Sans JP）。
  以前は埋め込みフォントで17MBあったが、CDN化して1MB台に落とした経緯がある。
  **フォントを再び埋め込まないこと。**
- YouTube 3本を iframe で埋め込み。遅延読み込みはしていない。

### なぜインラインstyleなのか

元がデザインツール上の Design Component で、そこではインラインstyleが必須だった。
静的HTMLに書き出したあともその方針を維持している。
理由は、セクション単位でコピー&ペーストすれば見た目がそのまま複製できて、
非エンジニアでも部分的に手を入れやすいから。
CSSファイルに切り出す「整理」はしないでほしい。

### レスポンシブの仕組み

`@media (max-width: 760px)` 1ブロックで、`[style*="..."]` 属性セレクタを使って
インラインstyleを `!important` で上書きしている。変則的な手法。

```css
[style*="grid-template-columns"] { grid-template-columns: 1fr !important; }
```

つまり **grid を使ったセクションは自動的にスマホで1カラムになる**。
新しいgridを追加してこの挙動が困る場合は、メディアクエリ側に個別の例外を書く。

## 4. コンテンツの出どころ

すべて米倉さん本人から提供された情報。`docs/CONTENT.md` に
掲載中の事実とURLを一覧化してある。数字・年月・団体名を変更するときは
必ず本人確認を取り、`CONTENT.md` も同時に更新すること。

推測で埋めた箇所はない。不明な点は空欄にせず、その項目自体を載せていない。

## 5. 未対応・改善余地

- **OG画像が専用画像ではない**。いまはポートレート写真を流用している。
  横長のOG専用画像（1200×630）を用意できるとSNSシェア時の見栄えが上がる。
- **ロゴ画像がJPEG**。背景が白なのでカード背景（`#FCFAF4`）との境界に
  わずかに白フチが出る可能性がある。`mix-blend-mode: multiply` で
  ほぼ目立たなくしているが、透過PNGに差し替えるのが本来の解。
- **YouTube iframe が3本ある**ため初回読み込みがやや重い。
  サムネイル画像 → クリックで iframe 差し込み、にすると軽くなる。
- **画像に `loading="lazy"` を付けていない**。付けると初期表示が速くなる。
- **町田院は2026年夏オープン予定**。オープンしたら
  Timeline / Activities / LINE CTA まわりの記述を「予定」から実績に変える。

## 6. 更新頻度の想定

学会発表とメディア掲載が年に数回増える。
その2セクションだけ差分更新する運用を想定している。
`data-screen-label="Media"` と `="Research"` を grep すれば該当箇所にすぐ着く。
