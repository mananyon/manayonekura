## 1. エグゼクティブサマリー

### 1-1. 本企画書が答える問い

> **4,980円の店のオーナーが、同じ住所で28,000円の施術をどう成立させるか。**

答えは3つです。

1. **オーナーは自分の店の価格では働かない。** 雇用に変わったことで、この根拠はさらに強くなりました（4章）
2. **ねここちは"入口"、ここちめいどは"最上位"。** カニバリではなく、階段にする
3. **ねここちからの収入は"施術"ではなく"仕組み"で取る。** 監修料・採用支援・持分

### 1-2. 結論

| 項目 | 決定 |
|---|---|
| 東京での自分の商品 | **ここちめいど町田院 90分 28,000円**（初回120分 35,000円） |
| ねここちでの施術 | **原則ゼロ。**監修・教育・症例DBで関わる |
| 稼働 | **毎週水曜（月4回）＋ 月2回は木曜も滞在** ＝ 月6営業日 ／ 月18〜22枠 |
| 予約公開 | 完全紹介・LINE限定。**HPBには絶対に載せない** |
| ねここちからの対価 | **技術監修料（売上の3〜5%）＋ 採用・教育支援フィー ＋ 持分配当** |
| 集客 | 広告ゼロ。**「町田は毎週水曜」を覚えてもらう ＋ ねここち会員からの引き上げ** |
| 自由度の守り方 | **年間メンバーシップ（優先予約権）**で収入を稼働から切り離す |

### 1-3. 「毎週水曜」が効く3つの理由 ★

水曜固定は、単なるスケジュールではなく**戦略的なフィルター**として機能します。

| 理由 | 内容 |
|---|---|
| **① ターゲットが自動で絞られる** | 平日昼に動けるのは、経営者・フリーランス・シフト制・休職中・主婦層。**まさに「自由度が高い人」だけが残る**。会社員を無理に取りに行かなくてよくなる |
| **② 同業者の定休日** | 水曜は治療院・美容室・医療機関の定休日が多い。**看護師・心理士・鍼灸師（ペルソナB）が最も来やすい曜日** |
| **③ 曜日で覚えてもらえる** | 「不定期です」ではなく「**町田は毎週水曜日**」。これが言えると、告知コストがほぼゼロになり、「日程が読めない」という最大の弱点が消える |

> **「日程に合わせて来てもらう」ための最強の仕掛けは、日程を単純にすることです。**
> 先出しカレンダーより、「毎週水曜」の一言のほうが強い。

## 2. 労働契約への変更が意味すること ★

**業務委託50% → 労働契約（1〜2名）**。この変更は、ねここちの収支構造を根本から変えます。
米倉さんの働き方にも直結するので、先に整理します。

### 2-1. 何が変わるか

| | 業務委託50%（当初案） | **労働契約（変更後）** |
|---|---|---|
| 人件費 | 売上の50%（変動費） | **月給＋社保（固定費）** |
| 売上ゼロの月 | 人件費ゼロ | **満額支払う** |
| 満席時の利益 | 少ない | **大きい** |
| 品質の統制 | 指揮命令できない | **できる（教育が効く）** |
| 標準化・FC展開 | ばらつきが出る | **しやすい** |
| 偽装請負リスク | あり | **なし** |
| 労務管理 | 不要 | **必要**（労働時間・有給・社保・労災） |
| 採用失敗のコスト | 低い | **高い**（簡単に辞めさせられない） |

**結論：満席になれば労働契約の方が儲かる。ただし、そこまでのキャッシュが持つかが勝負になります。**

### 2-2. 損益分岐が生まれた

想定固定費（1名体制・月額）

| 項目 | 金額 |
|---|---|
| 人件費（月給30万＋社会保険 会社負担 約15%） | 350,000円 |
| 家賃（町田駅圏・小規模店舗） | 300,000円 |
| HPB掲載費 | 50,000円 |
| 水道光熱・消耗品・システム・保険 | 100,000円 |
| **固定費 合計** | **800,000円** |

会員1人あたりの月次売上：**約6,636円**
（提供資料のミックス：月1会員150人＋月2会員50人＋都度20人 ＝ 売上146万円 ÷ 220人）

| 体制 | 固定費 | **損益分岐 会員数** |
|---|---|---|
| **1名** | 800,000円 | **約121人** |
| 2名 | 1,150,000円 | 約173人 |

### 2-3. 立ち上がり期の運転資金 ★ 最重要

会員がゼロから121人に積み上がるまで、毎月赤字が出ます。**ここを見誤ると事業が死にます。**

会員が月20人ずつ増える想定（1名体制）

| 月 | 会員数 | 売上 | 固定費 | 損益 |
|---|---|---|---|---|
| 1ヶ月目 | 20人 | 133,000円 | 800,000円 | ▲667,000円 |
| 2ヶ月目 | 40人 | 265,000円 | 800,000円 | ▲535,000円 |
| 3ヶ月目 | 60人 | 398,000円 | 800,000円 | ▲402,000円 |
| 4ヶ月目 | 80人 | 531,000円 | 800,000円 | ▲269,000円 |
| 5ヶ月目 | 100人 | 664,000円 | 800,000円 | ▲136,000円 |
| 6ヶ月目 | 121人 | 803,000円 | 800,000円 | ±0 |
| | | | **累積赤字** | **約 201万円** |

> **必要運転資金：250〜300万円。**（採用が遅れる／会員の伸びが月15人なら400万円）

### 2-4. だから「1名で始める」

| | 1名で開業 | 2名で開業 |
|---|---|---|
| 損益分岐 会員数 | **121人** | 173人 |
| 立ち上がり累積赤字 | **約201万円** | 約400万円 |
| 必要運転資金 | **250〜300万円** | 450〜550万円 |
| 施術キャパ | 月220〜352回 | 月440〜704回 |

**1名のキャパ（月220〜352回）は、会員150〜220人分に相当します。**
2人目は、**会員が150人を超えて、かつ予約が取れない状態が2ヶ月続いてから**。それ以前に雇うと、固定費だけが先に立ちます。

## 3. 稼働設計 — 毎週水曜をどう組むか

### 3-1. 3つの組み方

| | A 毎週水曜のみ | B 水木1泊 × 月3回 | **C 推奨：ハイブリッド** |
|---|---|---|---|
| 内容 | 水曜のみ日帰り | 水木を月3回 | **毎週水曜（月4回）＋ 月2回は木曜も** |
| 営業日／月 | 4〜5日 | 6日 | **6日** |
| 遠征回数 | 4〜5往復 | 3往復 | 4往復（うち2回は1泊） |
| 交通費 | 103,500円 | 69,000円 | 92,000円 |
| 宿泊費 | 0円 | 33,000円 | 22,000円 |
| **月固定費** | **103,500円** | **102,000円** | **114,000円** |
| 枠数／月 | 16〜20枠 | 21枠 | **22枠**（計画基準18枠） |
| 「毎週水曜」と言えるか | ○ | **✕**（週が抜ける） | **◎** |

- **雇用に変わった以上、定期的な現場管理が必須。**木曜午前を教育・面談・症例カンファに充てられる
- 週が抜けないので、**継続患者が予約リズムを作れる**

## 4. 「オーナーに見合う価格帯」— 数字で出す

### 4-1. 雇用に変わって、答えがさらに明確になった

業務委託なら、米倉さんが施術に入れば売上の50%が本人に入りました。
**雇用では、それすらありません。**従業員に払う給与は、彼女が施術しても発生します。

| 米倉さんが1時間をどこに置くか | **限界価値（時給）** |
|---|---|
| **ねここちの枠に入る**（従業員がいる前提。人件費の節約分のみ） | **約 2,200円** |
| 四日市 ここちめいど（60分 14,000円） | 14,000円 |
| **町田 ここちめいど（90分 28,000円）** | **18,667円** |
| ねここち 技術監修（2店舗 × 売上4%） | **施術時間ゼロで月 116,800円** |

> 鍼灸師の人件費：月給30万＋社保 ＝ 約34.5万 ÷ 160時間 ＝ **時給 約2,150円**。
> つまり米倉さんがねここちで1時間施術しても、店が得るのは「その1時間分の人件費が浮く」効果だけ。
> **町田の枠に入れば18,667円。差は約16,500円／時。**

**例外**：予約が取れないほど需要が超過している場合は、増枠分が店舗売上（時給11,000〜14,000円）になります。
ただしそれは**「2人目を雇う」で解くべき問題**であって、オーナーが埋めて解決してはいけません。埋めると、2人目を雇う判断が永久に先送りされます。

### 4-2. 45時間をどう使うか

東京で使える時間は月45時間（6日 × 7.5時間）。

| 使い方 | 月収 |
|---|---|
| 全部ここちめいど（18枠 × 28,000円） | **504,000円** |
| 全部ねここち（人件費の節約分として） | 約 99,000円 |

**同じ45時間で、5倍の差**が出ます。

### 4-3. これは効率の話だけではない

| もしオーナーが施術に入ったら | 何が起きるか |
|---|---|
| 「米倉さんに30分5,500円で診てもらえる」 | 28,000円の枠が二度と売れなくなる |
| **雇った従業員と同じ仕事をする** | **「オーナーの方が上手い」が店内で常時比較される。従業員が育たず、辞める** |
| 「オーナーが現場を回している」 | 2人目を雇う判断が遅れ、FC加盟希望者が引く |
| 「米倉まな＝ヘッドスパの人」 | 学会・医科連携・メディアでの立ち位置が崩れる |

> **オーナーが自分の店の最低単価で働き始めた瞬間、その店の上限価格はオーナーの単価になります。**
> **雇用ではさらに、従業員の成長機会まで奪います。**

### 4-4. 米倉さんの3つの役割

| 役割 | 内容 | 対価 |
|---|---|---|
| **技術監修者** | 頭皮鍼プロトコル・施術マニュアル・安全基準・効果検証 | 技術監修料（3〜5%） |
| **採用・教育責任者** | ここちはりネットワークからの採用、入職後の教育、水曜夜・木曜午前の面談 | 採用・教育支援フィー |
| **エビデンス責任者** | 症例データの蓄積・学会報告・「医学的根拠」の担保 | ブランド使用料に内包 |

**この3つはすべて時間に比例しません。**だから店舗が増えるほど収入が増え、東京にいる日数は増えない。

## 5. 価格設計

### 5-1. 4,980円 と 28,000円 のあいだは、意図的に空ける

```
  28,000円  ████████████████████  ここちめいど町田院（90分・米倉まな本人）
            ┊
            ┊  12,000〜18,000円 ← 何も置かない
            ┊
   7,000円  ████                  ねここち 都度利用
   4,980円  ███                   ねここち 初回体験
```

中間価格帯を作ると、上と下の両方から食われます。
特に **「院長施術 60分 14,000円」をねここちのメニューに置かないこと。**置いた瞬間に階段が壊れます。

### 5-2. 28,000円の根拠

| | 内容 |
|---|---|
| ① 時間が違う | 四日市60分 → 町田90分（傾聴の比重を上げる） |
| ② 出張費込み | 三重から往復。移動と宿泊の実費が乗っている |
| ③ 枠が限られる | 毎週水曜・月18〜22枠のみ |
| ④ ねここちとの階段 | 4,980 → 7,000 → **28,000**。中間を作らない |
| ⑤ 実績 | 修士／学会4報／産学連携／精神神経学会シンポジスト／のべ20,000人 |

> 東京の相場は自律神経・うつ対応で **60分5,500〜6,800円**。ねここちの都度7,000円はまさにこの相場帯。
> **ここちめいどは、その市場に降りない。**

### 5-3. メニュー表

| メニュー | 時間 | 価格 | 内容 |
|---|---|---|---|
| 初回 | 120分 | **35,000円** | 問診・傾聴・施術・セルフケア指導・回復計画の設計 |
| 通常 | 90分 | **28,000円** | 傾聴＋施術 |
| 継続者短時間 | 60分 | **20,000円** | 状態が安定した方の維持（2回目以降のみ） |
| 3回券 | 90分×3 | **78,000円**（1回26,000円／6ヶ月有効） | |
| 6回券 | 90分×6 | **150,000円**（1回25,000円／12ヶ月有効） | |
| オンライン傾聴 | 60分 | **12,000円** | 来られない週のつなぎ |
| **年間メンバーシップ** | 12回／年 | **330,000円** | ★下記 |

### 5-4. 年間メンバーシップ

| 特典 | 内容 |
|---|---|
| **優先予約権** | 水曜枠の公開が、一般より**48時間早い** |
| 繰越可 | 忙しい月は使わなくてよい（年12回を自分のペースで） |
| キャンセル枠の優先案内 | 空きが出たら最初に声がかかる |
| オンライン振替 | 来られない月は60分オンライン傾聴に振替可 |
| 両院で使える | 四日市・町田どちらでも |

**8名で年間264万円が、期初に確定します。**
自由でいるためには、収入が予約数に連動しない仕組みが要る。これがその設計です。

### 5-5. 四日市の価格は据え置く

HPBは価格比較の場です。28,000円をそこに置けば、必ず価格で負けます。

### 10-2. 「毎週水曜」を、そのまま広告文にする

告知の主語を「不定期の出張」から「**曜日**」に変えてください。

| ❌ 従来の言い方 | ✅ 水曜固定の言い方 |
|---|---|
| 「不定期で東京に伺います」 | **「毎週水曜日、町田にいます。」** |
| 「日程が出たらお知らせします」 | 「水曜が空いている方だけ、どうぞ。」 |
| 「ご予約はお早めに」 | 「今月の水曜は 10/7・14・21・28 です。」 |

**この一言で、次の3つが同時に解決します。**

1. 患者が自分の予定に組み込める（毎週同じ曜日だから覚えられる）
2. 平日昼に動けない人は自然に離脱する（＝**ターゲットが自動で絞られる**）
3. 告知の手間がほぼゼロになる（毎月の日付告知だけでよい）

### 10-3. 二段ファネル

```
 【ねここちが広告費を払って集める】
 HPB → 初回4,980円 → LINE登録 → 月額会員（5,500〜9,900円）
                                      │
                                      │ 従業員が気づく：
                                      │ ・眠れない日が続いている
                                      │ ・心療内科に通っている / 迷っている
                                      │ ・30分では追いつかない
                                      ▼
                        ┌──────────────────────────┐
                        │  引き上げ相談枠（木曜13:00）  │
                        │  米倉まな・30分・無料 or 5,000円 │
                        └──────────────────────────┘
                                      ▼
                     ここちめいど 初回 120分 35,000円
```

**米倉さんは、広告費を1円も払わずに枠を埋められます。**
ねここちが月220回の接点を持つなら、そのうち5%が症状レベル ＝ **月11人**。18枠を埋めるには十分です。

### 10-4. 引き上げの作法

| ✅ やる | ❌ やらない |

| 「30分のケアでは追いつかない状態です」と**理由を言う** | 「もっと良いコースがあります」と言う |
| 引き上げなかった人には**そのままねここちを続けてもらう** | 会員を減らす方向に動く |
| 紹介インセンティブを制度化（1件5,000円など） | 従業員に成果ノルマを課す |

## 14. リスクと対応

| リスク | 影響 | 対応 |
|---|---|---|
| **カニバリ**（28,000円が売れなくなる） | 致命的 | 6章の7つの分離ルールを厳守。特に「HPB非掲載」「オーナーは施術に入らない」 |
| **ねここちに施術者として引きずり込まれる** | 致命的 | **契約書に「施術義務を負わない」条項**（8-3）。雇用では従業員の仕事を奪うことにもなる |
| **立ち上がり期のキャッシュ切れ** | 致命的 | 運転資金250〜300万円を先に確保。**1名で開業する**（2名同時は避ける） |
| **1名の離職＝売上ゼロ** | 大 | ここちはりネットワークをバックアップに。採用は1名でも慎重に |
| 届出・法規の不備 | 事業停止 | 開始前に町田市保健所へ相談（11章 #1・#2） |
| 労務トラブル | 大 | 就業規則・雇用契約書を社労士と整備（11章 #4） |
| 商標の取り漏れ | FC停止 | 開業前に出願（11章 #3） |
| 共同オーナーとの認識齟齬 | 事業解消 | 8-3 の条項を文書化。特に運転資金の負担と意思決定権 |
| ねここちの会員が集まらない | 大 | ここちめいどは**既存資産だけでも18枠埋まる**設計に。ねここち依存にしない |
| **水曜に来られない層を取りこぼす** | 中 | 月2回の木曜枠と、オンライン傾聴で受ける。**無理に他曜日を増やさない** |
| 稼働率が上がらない | 中 | 損益分岐23%（4.1枠）。**4枠未満の水曜は中止する判断ルール**を事前に決めておく |
| 当日キャンセル | 中 | 事前決済＋キャンセルポリシー |
| 移動疲労 | 中 | 水曜4枠・木曜3枠を上限として固定。増やさない |
| 四日市の水曜休診による不満 | 中 | 事前告知＋他曜日への振替案内 |
| 町田が四日市の稼働を削る | 中 | 水曜＋月2回の木曜で固定。それ以上は増やさない |
