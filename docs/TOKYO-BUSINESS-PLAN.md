### 2-2. 「毎週水曜・隔週木曜」に絞る理由

水曜も木曜も毎週東京にいるので、**技術的には月8〜9日施術できます**。
それでも月6〜7日に抑えるべき理由は3つ。

1. **月6回程度という当初の希望を守る。**施術日を増やすほど、監修・研究に使う時間が消える
2. **1日4枠 × 90分は、記録と傾聴を含めると実質10時間拘束。**連日は続かない
3. **枠を絞ることが価格の根拠になる。**「月24枠しかない」から28,000円が成立する

> **需要が明らかに超過したら、値上げが先。施術日を増やすのは最後の手段です。**
> 月8〜9日にすれば売上は約1.4倍になりますが、そのぶん監修料・印税・サロンという
> 「時間に比例しない収入」を育てる時間が消えます。

## 3. 自宅兼院という構造 ★

住居を別に借りる必要がなくなった代わりに、**まったく別の論点が5つ**立ち上がります。
どれも「あとから直せない」種類のものです。

### 3-1. 経済的には、圧倒的に有利

前案（東京に1Kを借り、ねここちは別に店舗を借りる）との比較。

| | 前案：住居＋店舗を別々に | **自宅兼院** |
|---|---|---|
| 東京の住居 | 75,000円 | 建物に含まれる |
| ねここちの店舗家賃 | 300,000円 | 建物に含まれる |
| **場所コスト 合計** | **375,000円／月** | **200,000円／月**（仮置き） |
| 差額 | — | **▲175,000円／月 ＝ 年210万円** |
| 通勤 | あり | **ゼロ** |
| 1階の稼働 | — | ここちめいど月6日＋ねここち月20日で**ほぼ埋まる** |

**年210万円の削減は、ねここちの立ち上がり赤字（約127万円）を1年で吸収してしまう規模です。**

### 3-2. ★ 1階を、ねここちに無償で使わせないこと

これが本章でいちばん重要です。

自宅の家賃・ローンを払っているのは米倉さん個人。そこにねここち（共同事業）が入るなら、
**適正な賃料を、ねここちから受け取ってください。**

| 理由 | 内容 |
|---|---|
| **① 共同オーナーとの公平性** | 無償提供は、米倉さんが一方的に資産を持ち出す形。あとで必ず揉めます |
| **② FCモデルの再現性** | **加盟店は家賃を払います。**直営1号店だけ家賃ゼロだと、収支モデルが加盟店に再現できない。「1号店は家賃がかからない特殊例でした」ではFCは売れません |
| **③ 税務の整理** | 事業用と居住用の按分、賃料収入の計上。曖昧にすると税務調査で否認されます |

**提案：1階の適正賃料 月150,000円**（町田駅圏の小規模店舗相場を踏まえた仮置き）

| | 金額 |
|---|---|
| 建物全体のコスト（仮置き） | 200,000円／月 |
| ねここちから受け取る1階賃料 | **＋150,000円／月** |
| **米倉さんの実質住居負担** | **50,000円／月** |

> ここちめいども1階を月6〜7日使います。ここは内部按分として **月30,000円** をここちめいどの原価に置きます（4章）。
> 実務上の処理（不動産所得か事業収入か、按分の根拠）は**税理士に必ず確認してください**。

### 3-3. ★ オーナー不在の5日間、自宅で従業員が営業する

隔週で5日間、米倉さんは四日市にいます。そのあいだ、**雇った鍼灸師が、米倉さんの自宅1階で営業します。**

これは前案（外部店舗）にはなかった論点です。設計しておくべきこと。

| 項目 | 決めておくこと |
|---|---|
| 鍵の管理 | 従業員に渡す鍵は**1階部分のみ**。2階への動線は施錠して物理的に分ける |
| 施錠・開錠の手順 | 開店・閉店のチェックリストを紙で用意。スマートロックの履歴管理を推奨 |
| 金銭管理 | 現金を置かない。**キャッシュレス決済のみ**にするのが最も安全 |
| 緊急連絡 | 四日市滞在中の連絡体制。急病・設備トラブル・クレームの一次対応 |
| 防犯カメラ | 1階の出入口と待合。従業員にも事前に説明しておく |
| 2階の扱い | **従業員は2階に立ち入らない**ことを雇用契約書に明記 |

> **これが成立するかどうかは、採用の質にすべてかかっています。**
> 「自宅を任せられる人」を1人採る——ここちはりネットワークからの採用を強く勧める理由が、もう一つ増えました。

### 3-4. ★ 施術所としての構造設備基準（自宅兼だとシビアになる）

あはき法施行規則の施術所基準は、自宅兼でも当然に適用されます。**1階でこれを満たす必要があります。**

| 基準 | 内容 |
|---|---|
| 専用の施術室 | **6.6㎡以上**。他の用途と兼ねられない |
| 待合室 | **3.3㎡以上** |
| 換気 | 施術室の**床面積の1/7以上**の外気開口部（または換気装置） |
| 消毒設備 | 手洗い・器具消毒の設備 |
| **居住部分との区画** | **施術所と住居を明確に区画すること。**ここが自宅兼で最も指摘される点 |

**確認すべきこと**

- [ ] 1階で施術室を**2室**とれるか（ここちめいどとねここちを並行運用するなら必須）
- [ ] 1階専用の出入口があるか。なければ設けられるか
- [ ] トイレ・洗面を、来客と居住で分けられるか
- [ ] 内装工事の見積り（施術所仕様への改装。**200〜500万円規模になる可能性**。運転資金とは別枠で見ておく）
- [ ] **用途地域の確認**。第一種低層住居専用地域だと店舗面積に制限がかかる（原町田4丁目は町田駅至近なので商業系と思われるが、必ず役所で確認）
- [ ] 看板の設置可否（屋外広告物条例）

### 3-5. ★ 自宅住所が、HPBに載る

ねここちはHPB集客が前提です。つまり**自宅の住所が、不特定多数に公開されます。**

| リスク | 対応 |
|---|---|
| 自宅住所の公開 | 覚悟のうえで決めるしかない。**ただし「2階が住居」であることは公開しない** |
| 見知らぬ来客 | **完全予約制**にする（HPBの当日予約枠を開けない運用も可能） |
| 2階への侵入 | 階段の施錠・目隠し。動線を物理的に遮断 |
| 女性スタッフの安全 | 防犯カメラ、緊急通報装置、施術中の施錠ルール |
| 夜間営業 | 遅い時間帯の枠を開けるかは慎重に。**ねここちの営業時間の上限を決めておく** |

> ここちめいど（完全紹介制・LINEのみ）は、そもそも住所を公開しません。
> **住所が出るのはねここち側だけ**という構造は、意外にも防御になっています。

### 3-6. 税務：住居と事業の按分

**税理士案件です。**開業前に必ず相談してください。

| 論点 | 内容 |
|---|---|
| 家賃・ローンの按分 | 床面積按分が基本。1階事業・2階居住で概ね50%ずつ |
| **住宅ローン控除** | 購入の場合、**居住用部分が床面積の50%以上**でないと適用できない。1階/2階が同面積なら**ぎりぎり**。控除額も居住割合で按分される |
| 水道光熱費・通信費 | 使用実態に応じて按分 |
| 固定資産税 | 事業用部分は経費算入可 |
| 減価償却 | 購入の場合、建物の事業用部分 |

## 6. 「オーナーに見合う価格帯」

### 6-1. 雇用に変わって、答えがさらに明確になった

業務委託なら、米倉さんが施術に入れば売上の50%が本人に入りました。**雇用では、それすらありません。**

| 米倉さんが1時間をどこに置くか | **限界価値（時給）** |
|---|---|
| **ねここちの枠に入る**（従業員がいる前提。人件費の節約分のみ） | **約 2,200円** |
| 四日市 ここちめいど（60分 14,000円） | 14,000円 |
| **町田 ここちめいど（90分 28,000円）** | **18,667円** |
| ねここち 技術監修（2店舗 × 売上4%） | **施術時間ゼロで月 116,800円** |

> 鍼灸師の人件費：月給30万＋社保 ＝ 約34.5万 ÷ 160時間 ＝ **時給 約2,150円**。

**例外**：予約が取れないほど需要が超過している場合は、増枠分が店舗売上（時給11,000〜14,000円）になります。
ただしそれは**「2人目を雇う」で解くべき問題**です。オーナーが埋めると、2人目を雇う判断が永久に先送りされます。

### 6-2. 東京の13日を、施術で埋めないこと ★

|---|---|
| 施術で埋める（+13日 × 4枠 × 28,000円） | +1,456,000円（ただし完全に時間に比例。体力の上限で頭打ち） |
| **監修・研究・執筆・サロンに使う** | **監修料は店舗が増えれば増える。印税・サロン収入は寝ていても入る** |

施術で埋めた13日は、来月また同じ13日を埋め直さないと消えます。

> **空白は、怠けではなく投資です。**
> それを守るために、月6日という上限を最初に決めておいてください。
