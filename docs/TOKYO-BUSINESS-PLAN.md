### 2-2. 「毎週水曜・隔週木曜」に絞る理由

水曜も木曜も毎週東京にいるので、**技術的には月8〜9日施術できます**。
それでも月6〜7日に抑えるべき理由は3つ。

1. **月6回程度という当初の希望を守る。**施術日を増やすほど、監修・研究に使う時間が消える
2. **1日4枠 × 90分は、記録と傾聴を含めると実質10時間拘束。**連日は続かない
3. **枠を絞ることが価格の根拠になる。**「月24枠しかない」から28,000円が成立する

> **需要が明らかに超過したら、値上げが先。施術日を増やすのは最後の手段です。**
> 月8〜9日にすれば売上は約1.4倍になりますが、そのぶん**ねここちの会員基盤・研究・執筆・サロン**という
> 「積み上がる収入」を育てる時間が消えます（6-2）。

### 3-1. ★ 訂正：1階の「賃料」は成立しません

**前版では「ねここちから月150,000円の賃料を受け取る」を中心的な提案としていましたが、これは撤回します。**
ねここちが米倉さんの個人事業である以上、**自分から自分に家賃は払えません。**

代わりにこうなります。

| | 前版（ねここちが別事業者） | **今回（同一の個人事業）** |
|---|---|---|
| 1階の扱い | ねここちへ賃貸。**賃料収入 年180万** | **家事按分で経費計上** |
| 会計上の効果 | 売上が180万増える | **経費が増える（＝節税になる）** |
| 実際のキャッシュ | ねここちから個人へ移動 | **動かない** |

**家事按分の考え方**

| 項目 | 按分 |
|---|---|
| 家賃 or ローン利息・減価償却 | 床面積按分。**1階事業・2階居住で概ね50%** |
| 水道光熱費・通信費 | 使用実態に応じて |
| 固定資産税（持ち家） | 事業用部分 |

> **扉も鍵も別**なので、区画の根拠は明確に示せます。按分の説明がしやすいのは、この物件の実務上の利点です。
> 住宅ローン控除は**居住用が床面積の50%以上**必要。1階/2階が同面積ならぎりぎりなので、税理士に確認を。

### 3-2. ★ ただし「管理会計上の家賃」は計上し続けてください

実際のお金は動かなくても、**帳簿の外で1階の使用料を原価に入れておく**必要があります。理由は2つ。

| 理由 | 内容 |
|---|---|
| **① FCモデルの再現性** | **加盟店は家賃を払います。**直営1号店の収支に家賃が入っていないと、「1号店はオーナーの自宅だから安かった」という数字になり、加盟店に再現できない。**FCを売るなら、家賃込みの収支を示せることが前提です** |
| **② 判断を誤らないため** | 家賃ゼロの数字を見ていると、「ねここちは儲かっている」と錯覚します。**2店舗目を借りた瞬間に、月30万の家賃が現れる** |

**内部原価として置く金額（提案）**

| | 月額 |
|---|---|
| ねここち（月20日以上使用） | **150,000円** |
| ここちめいど（月6〜7日使用） | **30,000円** |

この2つは、税務申告には出てきません。**FC資料と経営判断のためだけに使う数字**です。
本書の収支は、この内部原価を入れた「管理会計ベース」と、実際のお金が動く「キャッシュベース」の両方を示します（7-3）。

### 3-3. オーナー不在の5日間、自宅で従業員が営業する

## 6. 「オーナーに見合う価格帯」

### 6-1. 米倉さんの1時間は、どこに置くといくらか

ねここちが自分の事業になっても、**答えは変わりません。**従業員に払う給与は、米倉さんが施術しても発生するからです。

| 米倉さんが1時間をどこに置くか | **限界価値（時給）** |
|---|---|
| **ねここちの枠に入る**（従業員がいる前提。人件費の節約分のみ） | **約 2,200円** |
| ねここちの枠を**増枠**として埋める（需要超過時・売上が全額入る） | 11,000〜14,000円 |
| 四日市 ここちめいど（60分 14,000円） | 14,000円 |
| **町田 ここちめいど（90分 28,000円）** | **18,667円** |

> 鍼灸師の人件費：月給30万＋社保 ＝ 約34.5万 ÷ 160時間 ＝ **時給 約2,150円**。
> 従業員が回している枠に米倉さんが入っても、得られるのは「その1時間分の人件費が浮く」効果だけ。
> **町田の枠に入れば18,667円。差は約16,500円／時。**

そして何より、それは**「2人目を雇う」で解くべき問題**です。オーナーが埋めると、2人目を雇う判断が永久に先送りされます。

### 8-4. ★ 個人事業に「共同オーナー」という器はありません

**ここが本章でいちばん重要です。**

個人事業主は1人です。**「持分」も「配当」も存在しません。**
前版で提案した「持分に応じた配当」は、この形では成立しません。**撤回します。**

共同オーナーとの関係は、次の3つのどれかになります。

| | **A. 任意組合（民法上の組合）** | **B. 業務委託** | C. 雇用 |
|---|---|---|---|
| 中身 | 共同事業として契約。**損益を持分割合で按分**し、各自が自分の所得として申告 | 米倉さんの個人事業。共同オーナーには**業務委託料**を払う | 給与を払う |
| 「共同オーナー」感 | ○ 実質的に対等 | △ 外注先になる | ✕ 部下になる |
| 損失の分担 | **持分に応じて分担** | しない（委託料は固定） | しない |
| 意思決定 | 組合契約で定める | 米倉さんが単独 | 米倉さんが単独 |
| 必要な書類 | **組合契約書（必須）** | 業務委託契約書 | 雇用契約書 |
| 税務 | 各自が組合損益を按分して申告 | 外注費／事業所得 | 給与／給与所得 |
| 難易度 | 高い（設計が要る） | **低い** | 低い |

**どれを選ぶにせよ、文書にしてください。**
個人事業で共同事業をやる最大の危険は、**法的な器がないぶん、全部が口約束になること**です。

**組合契約書（A案）に必ず入れる項目**

- [ ] 出資（金銭・労務・信用・ブランドをそれぞれいくらと評価するか）
- [ ] **損益の分配割合**（利益だけでなく**損失も**）
- [ ] 業務執行の分担と、**意思決定の方法**（価格変更・採用・出店・FC加盟承認）
- [ ] **米倉さんは施術義務を負わないこと** ★
- [ ] **月19.5日東京にいることを、労働の提供義務と混同しないこと** ★
- [ ] 1階の使用について（無償か、組合の経費として使用料を払うか）
- [ ] 脱退・解散の条件と、そのときの清算方法
- [ ] 競業避止の範囲
- [ ] 商標・ブランドの帰属

### 8-5. ★ 無限責任 — この形でいちばん大きなリスク

法人と違い、**個人事業には有限責任がありません。**

| 起こり得ること | 個人事業だと |
|---|---|
| 施術事故・賠償請求 | **米倉さん個人の財産で負う** |
| 従業員との労務トラブル | 同上 |
| ねここちの赤字・債務 | 同上 |
| 取引先とのトラブル | 同上 |

そして——**自宅が事業所です。**
最悪の場合、**事業のリスクが住まいに届く**構造になっています。

さらに、**共同オーナーがいるのに、法的な責任は米倉さん1人が負う**（B案・C案の場合）。
これは公平性の点でも危うい。A案（任意組合）でも、組合員は**無限責任**です。

**手当てとして、最低限これはやってください。**

- [ ] **賠償責任保険を、施術・雇用・施設の3方向で見直す**（従業員の施術、来客の転倒、自宅兼用であることを保険会社に伝える）
- [ ] **法人成りのトリガーを先に決める**（会員120人・4-6）。責任の切り分けは、法人化がいちばん確実な手段です
- [ ] **共同オーナーとの契約書に、損失の分担を明記する**（利益の話だけして、損失の話をしない契約が最も揉めます）

### 8-6. 「オーナーに見合う出し方」は、どう変わったか

前版では「賃料と監修料という、時間に比例しない対価を取る」でした。
**ねここちが自分の事業になったので、その形は消えました。**

代わりにこうなります。

> **ねここちの利益が、そのまま自分の所得になる。**
> **だからこそ、自分の時間を施術に使わず、ねここちが利益を出す仕組みのほうに使う。**

論旨は変わりません。**時間を売らない。**変わったのは、それが「対価の設計」から「**利益の出し方の設計**」になったことです。

## 14. リスクと対応

### 14-1. 解消したリスク
