### 1-3. ★ いちばん先に設計したいこと — FCコンサルへの「売上の4割」

**どの売上に掛かるかで、結論が正反対になります。そして「期間」も決める必要があります。**

| | 判定 |
|---|---|
| **【A案】本部の売上の40%** | ✅ **成立。**コンサルは本部業務（加盟店開拓・SV・研修）を担う。10店舗で月20万＋加盟金の40%（60万/件）。<br>**ただし無期限は不可**——本部に人を置けるのが17店舗になります（9-4b） |
| **【B案】加盟店（町田店）の売上の40%** | ✕ **破綻。**FC標準モデルの損益分岐が**会員178人**に。会員150人でも**月10万の赤字**。加盟店に提示できません |

**B案が成立して見えるのは、1号店が家賃ゼロだからです。**
家賃15万が乗る他店では、そもそも払えません（払える上限は売上の**14.6%**、標準モデルでは**ゼロ**）。

**そして、期間を切ってください。**

| | 本部に人（SV・事務）を置けるようになる店舗数 |
|---|---|
| **40%を払い続ける場合** | **16.7店舗** |
| 期間終了後 or 段階逓減後 | **10.0店舗** |

**7店舗ぶん遅れます。**そのあいだ、SVの質は米倉さん個人の時間で支えることになります。
FCコンサルの仕事は**立ち上げ期の仕事**なので、**期間限定（3〜5年）**か**段階逓減**（1〜5店舗40%／6〜10店舗25%／11店舗〜15%）を推奨します。
**逓減しても店舗数が増えるのでコンサルの受取額は減りません。本部だけが厚くなります**（9-4b）。

> **契約書に必ず書くこと**：「売上」の定義（どの事業体の、何を含むか）／期間／逓減の刻み／
> **成果物の権利帰属**（マニュアルの著作権が本部に来ないと、契約終了後に使えません）／
> **テール条項**（終了後も既存加盟店から取り続けるのか）（9-4c）。

### 2-2. 「毎週水曜・隔週木曜」に絞る理由

水曜も木曜も毎週東京にいるので、**技術的には月8〜9日施術できます**。
それでも月6〜7日に抑えるべき理由は3つ。

1. **月6回程度という当初の希望を守る。**施術日を増やすほど、監修・研究に使う時間が消える
2. **1日4枠 × 90分は、記録と傾聴を含めると実質10時間拘束。**連日は続かない
3. **枠を絞ることが価格の根拠になる。**「月24枠しかない」から28,000円が成立する

> **需要が明らかに超過したら、値上げが先。施術日を増やすのは最後の手段です。**
> 月8〜9日にすれば売上は約1.4倍になりますが、そのぶん**ねここちの会員基盤・研究・執筆・サロン**という
> 「積み上がる収入」を育てる時間が消えます（6-2）。

**前版では「ねここちから月150,000円の賃料を受け取る」を中心的な提案としていましたが、これは撤回します。**

**家事按分の考え方**

| 項目 | 按分 |
|---|---|
| 家賃 or ローン利息・減価償却 | 床面積按分。**1階事業・2階居住で概ね50%** |
| 水道光熱費・通信費 | 使用実態に応じて |
| 固定資産税（持ち家） | 事業用部分 |

> **扉も鍵も別**なので、区画の根拠は明確に示せます。按分の説明がしやすいのは、この物件の実務上の利点です。
> 住宅ローン控除は**居住用が床面積の50%以上**必要。1階/2階が同面積ならぎりぎりなので、税理士に確認を。

### 3-2. ★ ただし「管理会計上の家賃」は計上し続けてください

実際のお金は動かなくても、**帳簿の外で1階の使用料を原価に入れておく**必要があります。理由は2つ。

| 理由 | 内容 |
|---|---|
| **① FCモデルの再現性** | **加盟店は家賃を払います。**直営1号店の収支に家賃が入っていないと、「1号店はオーナーの自宅だから安かった」という数字になり、加盟店に再現できない。**FCを売るなら、家賃込みの収支を示せることが前提です** |
| **② 判断を誤らないため** | 家賃ゼロの数字を見ていると、「ねここちは儲かっている」と錯覚します。**2店舗目を借りた瞬間に、月30万の家賃が現れる** |

**内部原価として置く金額（提案）**

| | 月額 |
|---|---|
| ねここち（月20日以上使用） | **150,000円** |
| ここちめいど（月6〜7日使用） | **30,000円** |

この2つは、税務申告には出てきません。**FC資料と経営判断のためだけに使う数字**です。
本書の収支は、この内部原価を入れた「管理会計ベース」と、実際のお金が動く「キャッシュベース」の両方を示します（7-3）。

## 6. 「オーナーに見合う価格帯」

### 6-1. 米倉さんの1時間は、どこに置くといくらか

ねここちが自分の事業になっても、**答えは変わりません。**従業員に払う給与は、米倉さんが施術しても発生するからです。

| 米倉さんが1時間をどこに置くか | **限界価値（時給）** |
|---|---|
| **ねここちの枠に入る**（従業員がいる前提。人件費の節約分のみ） | **約 2,200円** |
| ねここちの枠を**増枠**として埋める（需要超過時・売上が全額入る） | 11,000〜14,000円 |
| 四日市 ここちめいど（60分 14,000円） | 14,000円 |
| **町田 ここちめいど（90分 28,000円）** | **18,667円** |

> 鍼灸師の人件費：月給30万＋社保 ＝ 約34.5万 ÷ 160時間 ＝ **時給 約2,150円**。
> 従業員が回している枠に米倉さんが入っても、得られるのは「その1時間分の人件費が浮く」効果だけ。
> **町田の枠に入れば18,667円。差は約16,500円／時。**

**需要超過で「増枠」になる場合**は、売上7,000円／30分が全額入るので時給14,000円。
前版（業務委託50%）より高くなりました。**それでも町田の18,667円には届きません。**
そして何より、それは**「2人目を雇う」で解くべき問題**です。オーナーが埋めると、2人目を雇う判断が永久に先送りされます。

### 6-2. 東京の13日を、施術で埋めないこと ★

月19.5日も東京にいて、1階が職場です。施術しているのは6日。残り13日が空いて見える。
**通勤ゼロなので、なおさら埋めたくなる。**

**でも、施術と会員では、増え方の性質が違います。**

| | 施術で埋める | **ねここちの仕組みに使う** |
|---|---|---|
| 性質 | **フロー。**1回売ったら消える | **ストック。**会員は積み上がる |
| 13日ぶんの価値 | +1,456,000円／月 | 会員が20人増えれば **月132,720円が翌月も、その次の月も入る** |
| 来月 | **また同じ13日を埋め直さないとゼロ** | **何もしなくても入り続ける** |
| 上限 | 体力（頭打ちがある） | 会員数（積み上がる） |
| 3年後 | 同じことをしている | **会員150人＝月100万円の基盤** |

**13日を仕組みに使い続けた結果が、ねここちの会員基盤です。**
施術で埋めた13日は、来月には何も残りません。

> **空白は、怠けではなく投資です。**
> それを守るために、施術日「月7日以下」を最初に決めておいてください（14章）。

## 9. FC本部と加盟店 ★

### 9-1. 5つの人格

| 主体 | 形態 | 役割 |
|---|---|---|
| **米倉まな個人（商標権者）** | 個人 | **「ねここち」商標を保有**し、本部に使用許諾を出す（9-2） |
| **合同会社ここちめいど** | 法人 | **FC本部（当面）** ＋ 四日市院。**オーナーは米倉さん単独** |
| **米倉まなの個人事業（東京）** | 個人事業 | **ねここち町田店（加盟店1号店）** ＋ ここちめいど町田院 ＋ オンライン傾聴 |
| **FCコンサル** | **業務委託** | FCパッケージ構築・加盟店開拓・SV。対価は**売上の4割**（★9-4で検証） |
| **（将来）株式会社ここちはり** | 法人 | 利益が出たら**本部機能を移す**（9-8） |

**ねここち町田店の鍼灸師1〜2名は、労働契約（雇用）です**（7章）。業務委託はFCコンサルのみ。

```
  米倉まな個人（商標権者）
        │ 商標使用許諾＋サブライセンス権
        ▼
  合同会社ここちめいど ＝ FC本部（当面）　オーナー：米倉まな単独
        │                    ▲
        │ FC契約              │ 業務委託（売上の4割）
        │ ロイヤリティ 5%      │
        ▼                    FCコンサル
  ねここち町田店（加盟店1号店）　←　鍼灸師1〜2名は労働契約
   ＝ 米倉まなの個人事業
        ＋ ここちめいど町田院・オンライン傾聴
```

**注目すべきは、ロイヤリティの行き先です。**
加盟店（米倉さんの個人事業）→ 本部（米倉さんの合同会社）。**同じ人の、左のポケットから右のポケット。**
ただし**法人と個人は別人格**なので、税務上はきちんと意味があります（9-6）。

### 9-2. ★ 商標を個人で持ち、法人に許諾する — 成立させる条件

**本書の前版では「本部法人名義で出願を」と書きましたが、個人保有＋ライセンスでも成立します。**
創業者がIPを個人で持ち、事業会社にライセンスする形は珍しくありません。ただし**3つだけ、外せない条件**があります。

| # | 条件 | なぜ |
|---|---|---|
| **①** | **サブライセンス（再許諾）権を、契約に明記する** | **これが最重要。**通常使用権者は、原則として第三者に再許諾できません。**本部が加盟店に「ねここち」を使わせる権利がないと、FCが成立しません** |
| **②** | **承継条項を入れる** | 将来 株式会社ここちはり に本部機能を移すとき（9-8）、ライセンスも一緒に動かせるようにしておく |
| **③** | **品質管理条項を入れる** | 商標権者には信用維持の管理義務があります。加盟店の施術品質を本部経由で管理する建て付けに |

**加盟店から見たときのリスクと、その緩和**

| リスク | 緩和策 |
|---|---|
| **本部の基盤が個人に依存して見える**（米倉さんに何かあれば商標は相続財産になる） | **専用使用権の設定登録**（特許庁に登録すれば第三者対抗力があります）／または**長期の許諾契約＋不解除特約** |
| ライセンスが切れたら加盟店が看板を使えなくなる | 契約期間を、FC契約の期間より長く設定する |

> **ライセンス料を有償にするなら、インボイスの判断が変わります。**
> 米倉さん個人に**BtoB売上が発生する**ため、本部（法人）が仕入税額控除のためにインボイスを求めます。
> 前版で「BtoB売上がほぼないので登録不要」と書きましたが、**ライセンス料の金額次第で再検討が要ります**（4-2）。
> 無償にするか、少額にとどめるなら影響は小さいままです。

### 9-3. ★ 1号店を「身内価格」にしてはいけない

**ロイヤリティが自分の会社に入るからこそ、率を甘くしたくなります。でも、してはいけません。**

| 理由 | 内容 |
|---|---|
| **① 他店への提示条件になる** | **1号店で決めた率が、そのまま2号店以降に適用されます** |
| **② 税務上の合理性の根拠になる** | ロイヤリティは**個人事業→自社法人への支払い**です。過大だと否認されますが、**「他店と同じ率」であることが、そのまま合理性の証明**になります |
| **③ 開示義務がある** | 予想収益を示すなら算定根拠の開示が必要（9-9）。1号店だけ条件が違うと、モデルが成立しません |

**①と②が、まったく同じ結論を指しています。**経営上の理由と税務上の理由が一致する——珍しく、迷わなくていい論点です。

**そして1号店の特殊条件は、必ず開示してください。**

- 家賃ゼロ（自宅1階）
- 内装済み
- オーナー＝監修者本人が常駐
- 加盟金・研修費を免除（**免除であることと、その対価が実証データの提供であることを契約に明記**）

### 9-4. ★★ FCコンサルへの「売上の4割」を設計する

**まず、どの売上に掛かるかを確定させてください。結論が正反対になります。**

#### 【A案】本部の売上（ロイヤリティ・加盟金等）の40% ← 自然な読み方

FCコンサルの仕事は**本部の仕事**（パッケージ構築・加盟店開拓・SV）なので、本部売上から払うのが筋です。

| 店舗数 | 本部のロイヤリティ収入／月 | **コンサル（40%）** | 本部手残り（60%） |
|---|---|---|---|
| 1店舗 | 49,770円 | **19,908円** | 29,862円 |
| 3店舗 | 149,310円 | **59,724円** | 89,586円 |
| 5店舗 | 248,850円 | **99,540円** | 149,310円 |
| 10店舗 | 497,700円 | **199,080円** | 298,620円 |
| 加盟金 150万円／件 | — | **600,000円／件** | 900,000円／件 |

**成立します。**1店舗のうちは月2万円なので、**加盟金の40%（60万円／件）が実質的な報酬**。
コンサルの報酬が**加盟ペースに直結する**——インセンティブとしては正しい向きです。

#### 【B案】ねここち町田店（加盟店）の売上の40% ← 採用してはいけない

| | 損益分岐 会員数 | 会員150人時の利益 |
|---|---|---|
| **1号店（家賃ゼロ）** | **137人** | **＋47,470円／月** |
| **FC標準モデル（家賃15万）** | **178人** | **▲102,530円／月** |

**FCとして成立しません。**標準モデルの損益分岐が会員178人——1名のキャパ（150〜220人分）のほぼ上限です。
「178人集めてやっと±0」という条件で加盟する人はいません。

> **B案が成立して見えるのは、1号店が家賃ゼロだからです。**
> 家賃15万が乗る他店では、払える上限は**売上の14.6%**、標準モデルでは**ゼロ**。
> **これも「1号店の特殊条件」の一つとして記録してください**（9-11）。

### 9-4b. ★ 40%を「無期限」にしないこと

A案でも、**期間を切らずに払い続けると本部が育ちません。**

| | 本部に人（SV・事務）を置けるようになる店舗数 |
|---|---|
| **40%を払い続ける場合** | **16.7店舗** |
| 40%が終わっている（または逓減後） | **10.0店舗** |

※ 本部にSV・事務を置く固定費を月50万円として試算

**7店舗ぶん、遅れます。**そのあいだ、SVの質は米倉さん個人の時間で支えることになります。

**そもそもFCコンサルの仕事は「立ち上げ期の仕事」です。**
パッケージを作り、最初の数店を開拓する——それが終わった後も本部売上の40%を永久に払う設計は、割に合いません。

#### 設計の選択肢

| | 内容 | 評価 |
|---|---|---|
| A. 定率・無期限（現案） | 本部売上の40%をずっと | △ シンプルだが、店舗が増えても本部に残らない |
| **B. 期間限定** | **立ち上げ3〜5年だけ40%。以降は終了または大幅逓減** | ✅ **推奨。**コンサルの仕事の性質に合っています |
| **C. 段階逓減** | 1〜5店舗40%／6〜10店舗25%／11店舗〜15% | ✅ **推奨。**本部の成長に応じて本部に残る |
| D. 成果連動 | 加盟金の40〜50%＋ロイヤリティは10〜20% | ○ 加盟店開拓が主業務なら合理的 |

**C案（段階逓減）の試算**

| 段階 | 本部売上／月 | コンサル | 本部手残り |
|---|---|---|---|
| 〜5店舗（40%） | 248,850円 | 99,540円 | 149,310円 |
| 〜10店舗（25%） | 497,700円 | 124,425円 | **373,275円** |
| 〜20店舗（15%） | 995,400円 | 149,310円 | **846,090円** |

**逓減しても、コンサルの受取額は減りません**（店舗数が増えるので）。
本部だけが厚くなる——**双方が納得しやすい形**です。

### 9-4c. FCコンサルとの業務委託契約 — 外せない4点

| # | 条項 | なぜ |
|---|---|---|
| **①** | **成果物の権利帰属を本部に** | **マニュアル・研修教材・開示書面の著作権が本部に移転していないと、契約終了後に使えなくなります。**これが最も見落とされます |
| **②** | **テール条項**（終了後の扱い） | 契約終了後も、既存加盟店のロイヤリティの40%を払い続けるのか。**決めておかないと必ず揉めます**。推奨：終了後2年で打ち切り、または一括清算 |
| **③** | **競業避止** | 同業（鍼灸・ヘッドスパ系）のFC本部を並行して支援しないこと。**ノウハウがそのまま競合に流れます** |
| **④** | **成果の定義とマイルストーン** | 「FCパッケージ一式」「開示書面」「加盟◯件」など。**何をもって役務提供完了とするか**。40%は成果に対する対価であって、在籍に対する対価ではありません |

**加えて**：秘密保持／再委託の可否／報酬の算定基礎（「売上」の定義を明記）／契約期間と更新。

> **FCコンサルへの報酬は、加盟店から見えません**（開示義務の対象外）。
> ただし**本部の体力に直結し、それはSVの質を通じて加盟店満足度に効きます。**
> 「見えないコスト」だからこそ、設計を甘くしないでください。

加盟店の収支（標準モデル・会員150人＝月商約100万円）

### 9-6. ロイヤリティは、所得分散にもなります

加盟店（個人事業）→ 本部（合同会社）への支払いは、**実質的には自分の中での移動**です。
でも法人と個人は別人格なので、**税務上はきちんと意味があります。**

| | 効果 |
|---|---|
| 個人事業（加盟店） | ロイヤリティが**経費**になり、事業所得が減る |
| 合同会社（本部） | 収入が増えるが、**法人実効税率は約23〜33%** |
| 個人の所得税・住民税 | 2年目で所得約988万。**最高税率帯に近づくほど、法人へ移す価値が大きくなる** |

> **ただし過大なロイヤリティは否認されます。**
> だからこそ **「他店と同じ5%」であることが、そのまま税務上の合理性の根拠**になります（9-3 ②）。

### 9-8. 株式会社ここちはり への移行

**当面は合同会社ここちめいどが本部を兼ね、利益が出たら株式会社ここちはりを立ち上げて本部機能を移す。**

> 育成とFC本部は、本質的に同じ機能です。**教えた人が加盟店になる**という導線が、法人として一本化されます。
> ここちはりの認定院ネットワークが、そのまま加盟候補プールになります。

**移行のトリガー：加盟店5店舗**

| 段階 | 本部の形 | 根拠 |

### 9-9. ★ 情報開示義務 — 1号店の実データが要る、法的な理由

**鍼灸は中小小売商業振興法の直接の対象外**（同法が法定開示書面を義務づけるのは小売業・飲食業）です。
ただし——

> **公正取引委員会「フランチャイズ・システムに関する独占禁止法上の考え方」により、
> 予想売上額・予想収益を示すなら、その算定根拠を加盟希望者に開示しなければなりません。**
> 根拠のない予想を示して勧誘すると、**ぎまん的顧客誘引（独禁法違反）**になり得ます。

**つまり、1号店の実データがないと、FCの募集自体ができません。**
「これぐらいかかった」を残す作業は、営業資料づくりであると同時に、**法的な要件でもあります。**

| 区分 | 開示すべき内容 |
|---|---|
| 本部の概要 | 商号・資本金・役員・直営店/加盟店数の推移 |
| 契約内容 | 加盟金・保証金・ロイヤリティの算定方法・契約期間・更新・解約条件 |
| **予想収益の根拠** | **モデル店舗の実績。1号店がこれになります** |
| 加盟店の負担 | 初期投資の内訳・運転資金・仕入義務 |
| 本部の提供内容 | 研修・SVの頻度と内容・商標使用許諾の範囲 |
| テリトリー | 独占権の有無と範囲 |
| 訴訟の有無 | 過去の紛争 |

### 9-12. 1号店で記録すべき「数字以外」のもの

**FCパッケージの中身は、金額よりむしろこちらです。**

| 記録する項目 | なぜ必要か |
|---|---|
| **採用にかかった期間・応募数・採用単価** | **加盟店の最大の不安。**「◯ヶ月で採れます」と言えるか |
| **教育に要した時間**（一人前になるまで） | 本部の研修プログラムの設計根拠 |
| **初回4,980円 → 会員 転換率** | 「HPB広告費は◯ヶ月で回収」と言える |
| **月次解約率** | LTV（顧客生涯価値）の計算根拠 |
| **会員獲得速度**（月何人） | 「◯ヶ月で黒字化」と言える |
| 1日あたり実施回数の実績 | 人員計画の根拠 |
| **物件の要件**（㎡・室数・設備・立地条件） | **加盟希望者の物件探しの条件書になる** |
| クレーム・ヒヤリハット | マニュアルと保険設計 |
| **保健所とのやりとりの手順** | **他市・他県の加盟店にも同じ手続きが要る。手順書にできる** |
| 使用した鍼・備品の型番と仕入先 | 物品供給の設計 |

| カウンセリングスクリプトと転換率の関係 | 会員化トークの標準化 |

> 施術で埋めればフロー（1回で消える）。会員を増やせばストック（積み上がる）。
> **FCパッケージを作れば、資産（他人に売れるもの）になります。**

### 9-13. 記録シートの形 — 5枚に分ける

**記録は「あとでまとめる」ができません。**開業前にシートを作り、その日のうちに埋める運用にしてください。
そのまま使える Excel を用意しています → `docs/ねここち_FC実証記録シート.xlsx`

|---|---|---|

| **② 月次記録** | 会員数・新規・解約・売上・費用・施術回数・稼働率 | **毎月1行。締めたその日に** |
| **③ 一時イベント** | 採用・教育・保健所・クレーム・設備。**所要時間と費用と「次回への申し送り」** | 発生の都度 |
| **④ 定性・要件** | 物件要件・設備リスト・仕入先と型番・HPB掲載文・スクリプト | 随時 |

> 加盟店にとって最大のコストは、お金ではなく**オーナーの時間**です。
> 「開業前の準備に何時間かかるか」を示せるFC本部は、ほとんどありません。

| **1号店を身内価格にしてしまう** | **大** | **1号店で決めたロイヤリティ率が、そのまま他店への提示条件になります。**同率を適用し、加盟金免除は契約に明記（9-3） |
| **1号店の特殊条件を開示しない** | **大** | 家賃ゼロ・内装済み・監修者が常駐。**隠すと加盟店から必ず問題にされます。**標準モデルとの差を開示する（9-11） |
| **払う側と受け取る側の利益相反** | 中〜大 | 2号店が加盟した瞬間に顕在化。**本部の意思決定を、米倉さん個人の店の都合から切り離す**（9-3） |
| **記録を取り損ねる** | **大** | 採用期間・転換率・解約率・保健所手順。**開業前に記録の枠組みを作る。あとから思い出せません**（9-12） |
| **家賃ゼロの数字で判断を誤る** | 中 | **内部保留15万を原価に置き続ける**（9-11）。2号店を借りた瞬間に月15万が現れます |
| **サブライセンス権を許諾契約に書き忘れる** | **FC停止** | 通常使用権者は原則、再許諾できません。**本部が加盟店に使わせる権利がなくなります**（9-2） |
| **FCコンサルへの40%が無期限になる** | **大** | **本部に人を置けるのが17店舗に遠のきます。**期間限定か段階逓減に（9-4b） |
| **成果物の権利が本部に来ない** | **大** | マニュアル・研修教材の著作権を本部帰属に。**契約終了後に使えなくなります**（9-4c） |
| **テール条項を決めていない** | 中〜大 | 契約終了後も既存加盟店の40%を払い続けるのか。決めないと必ず揉めます（9-4c） |
| 本部の固定費が先に立つ | 中 | **人を置くのは10店舗から**（逓減後）。当面は「契約と商標の器」として最小構成（9-5・9-4b） |
| 回収3年強が長い | 中 | 加盟金を抑える／内装を200万に収める／立ち上がりを早める。**30ヶ月以内が目標**（9-11） |
