### 2-2. 「毎週水曜・隔週木曜」に絞る理由

水曜も木曜も毎週東京にいるので、**技術的には月8〜9日施術できます**。
それでも月6〜7日に抑えるべき理由は3つ。

1. **月6回程度という当初の希望を守る。**施術日を増やすほど、監修・研究に使う時間が消える
2. **1日4枠 × 90分は、記録と傾聴を含めると実質10時間拘束。**連日は続かない
3. **枠を絞ることが価格の根拠になる。**「月24枠しかない」から28,000円が成立する

> **需要が明らかに超過したら、値上げが先。施術日を増やすのは最後の手段です。**
> 月8〜9日にすれば売上は約1.4倍になりますが、そのぶん監修料・印税・サロンという
> 「時間に比例しない収入」を育てる時間が消えます。

### 3-1. ★ 1階を、ねここちに無償で使わせないこと

ここが本章でいちばん重要です。

自宅の家賃・ローンを払っているのは米倉さん個人。そこにねここち（共同事業）が入るなら、
**適正な賃料を、ねここちから受け取ってください。**

| 理由 | 内容 |
|---|---|
| **① 共同オーナーとの公平性** | 無償提供は、米倉さんが一方的に資産を持ち出す形。あとで必ず揉めます |
| **② FCモデルの再現性** | **加盟店は家賃を払います。**直営1号店だけ家賃ゼロだと、収支モデルが加盟店に再現できない。「1号店は家賃がかからない特殊例でした」ではFCは売れません |
| **③ 個人／法人が分かれている以上、必須** | 東京は個人事業。**ねここちが別事業者なら、無償提供は税務上の寄附金・給与認定のリスク**。適正賃料でないと否認されます（4章） |

**提案：1階の適正賃料 月150,000円**（町田駅圏の小規模店舗相場を踏まえた仮置き）

| | 金額 |
|---|---|
| ねここちから受け取る1階賃料 | **150,000円／月 ＝ 年180万円** |
| 米倉さん個人事業の売上に計上 | 施術時間ゼロで発生する、いちばん堅い収入 |

> ここちめいども1階を月6〜7日使います。ここは内部按分として **月30,000円** をここちめいどの原価に置きます（4-4）。

### 3-2. オーナー不在の5日間、自宅で従業員が営業する

隔週で5日間、米倉さんは四日市にいます。そのあいだ、雇った鍼灸師が1階で営業します。
**扉も鍵も別なので、2階に入られる心配はありません。**残るのは運用ルールだけです。

| 項目 | 決めておくこと |
|---|---|
| 鍵 | **1階の鍵のみ**を渡す（2階は物理的に別なので、これで完結） |
| 施錠・開錠の手順 | 開店・閉店のチェックリスト。スマートロックの履歴管理を推奨 |
| 金銭管理 | 現金を置かない。**キャッシュレス決済のみ**にするのが最も安全 |
| 緊急連絡 | 四日市滞在中の連絡体制。急病・設備トラブル・クレームの一次対応 |
| 防犯カメラ | 1階の出入口と待合。従業員にも事前に説明しておく |
| 2階の扱い | 扉も鍵も別だが、**雇用契約書に「2階は業務範囲外」と一行入れておく**（トラブル時の線引きが明確になる） |

> ここちはりネットワークからの採用を強く勧める理由が、もう一つ増えました。

## 4. 二事業体制と収支 ★

**東京＝個人事業、四日市＝法人。**別人格の2つの事業体になったことで、
消費税・契約・患者情報の扱いが、それぞれ独立します。ここを先に整理します。

### 4-1. ★ 訂正：消費税は「合算」ではなく「事業体ごと」に判定する

**本書の前版では「東京＋四日市を合算して年商1,900万 → 課税事業者」と書きましたが、これは誤りです。**
事業者が別なら、課税売上高の判定も**別々**です。

| 事業体 | 年間売上（試算） | 1,000万円ライン |
|---|---|---|
| **個人事業（東京）** | 約 **1,030万円** | **超える** |
| **法人（四日市）** | 約 **907万円** | 下回る |

**「1,930万円の事業者が1つ」ではなく、「1,030万円と907万円の事業者が2つ」です。**
この差は、消費税の負担で年間100万円規模になり得ます。

> ただし課税事業者になるかどうかは、**その年ではなく基準期間（2期前）の課税売上高**で判定します。
> 個人事業（東京）を新たに始めるなら、**1〜2年目は原則として免税事業者**です。
> ——**インボイス登録をしなければ。**

### 4-2. インボイス登録するかどうかが、東京側の最初の分岐

個人事業（東京）の売上は、性質が2つに分かれます。

| 売上の相手 | 年間 | インボイスが要るか |
|---|---|---|
| **患者**（BtoC） | 約 670万円<br>（施術583万＋オンライン86万） | **不要**。個人客はインボイスを使わない |
| **ねここち**（BtoB） | 約 **360万円**<br>（監修料140万＋採用支援40万＋**賃料180万**） | **ねここちが課税事業者なら必要** |

**判断の中心はここです。**
ねここちが課税事業者の場合、米倉さん個人がインボイス未登録だと、**ねここちは年約36万円分の仕入税額控除を失います。**
共同事業の相手に、その負担を押しつける形になります。

| | 登録する | 登録しない |
|---|---|---|
| ねここち側 | 全額を仕入税額控除できる | **年約36万円の控除を失う** |
| 米倉さん側 | **売上1,030万すべてに消費税がかかる** | 免税（基準期間が1,000万以下の間） |
| 納税額（簡易課税・第五種） | **約 51.5万円／年** | 0円 |

**実務的な落としどころ**

- **簡易課税を選ぶ**（基準期間の課税売上5,000万以下で選択可）。事業区分は施術・監修＝第五種（みなし仕入率50%）、賃料＝第六種（40%）。**第五種が売上の75%以上を占めるので、特例で全体を第五種50%として計算できる見込み**
- 本則課税だと納税は約83万円と試算されるので、**簡易課税のほうが年30万円ほど有利**
- **簡易課税の届出は、適用したい課税期間が始まる前まで。**期限を逃すと1年待つことになります
- 登録しない場合は、**ねここちへの請求額を、控除できない分だけ抑える**（実質値引き）ことで折り合いをつける手もあります

> **どちらを選ぶかは、ねここちの事業主体（法人か／免税事業者か）が決まらないと確定できません。**
> 0-6 #1 を先に決めてください。

## 14. リスクと対応

### 14-1. 解消したリスク

| 前版で挙げていたリスク | 状態 |
|---|---|
| 1階が施術所の基準を満たさない | ✅ **クリア済み** |
| 内装費が想定を超える（200〜500万） | ✅ **概ね完了。不要に** |
| 2階への侵入・居住部分との区画 | ✅ **扉も鍵も別。物理的に解決** |
| 四日市の売上・患者が減る | ✅ **半年の運用実績あり** |
| 14日サイクルが体力的に続かない | ✅ **実質すでに検証中** |
| 13日の空白を施術で埋めてしまう | ✅ **埋めないと決定済み**（KPIで維持管理） |

**この計画の不確実性は、かなり減りました。**残るのは契約と税務、そして人です。

### 14-2. 残るリスク

| リスク | 影響 | 対応 |
|---|---|---|
| **ねここちの事業主体が決まらない** | **大** | ここが決まらないと賃料・監修料・インボイス・社保がすべて止まる。**最優先で決める**（0-6 #1） |
| **1階を無償で使わせてしまう** | 大 | 賃貸借契約を先に結ぶ（3-1）。**個人と別事業者のあいだの無償提供は、税務上も対人関係上も持ちません** |
| **ねここちに施術者として引きずり込まれる** | 致命的 | 契約書に「施術義務を負わない」「滞在＝労務ではない」条項（8-4）。**同じ建物に住んでいるぶん、この危険は高い** |
| **カニバリ**（28,000円が売れなくなる） | 致命的 | 8-3 の分離ルールを厳守。特に「HPB非掲載」「オーナーは施術に入らない」 |
| **個人／法人をまたぐ商品の整理漏れ** | 中〜大 | メンバーシップ・オンライン傾聴・カルテ共有（4-3）。**あとから直すのがいちばん面倒** |
| **インボイスの判断ミス** | 中 | 未登録ならねここちが年約36万円の控除を失う。登録なら年51.5万円の納税。**簡易課税の届出期限に注意**（4-2） |
| **1名の離職＝売上ゼロ** | 大 | ここちはりネットワークをバックアップに。**社保をつけられる体制（法人化）が、そのまま定着策になる**（7-5） |
| **立ち上がり期のキャッシュ切れ** | 大 | 運転資金150〜200万円を先に確保。1名で開業する |
| **不在5日間の運営トラブル** | 中 | 鍵は1階のみ・キャッシュレス限定・開閉店チェックリスト・緊急連絡体制（3-2） |
| **自宅住所がHPBで公開される** | 中 | 完全予約制／「2階が住居」であることは公開しない／防犯カメラ（3-3） |
| 商標の取り漏れ・帰属の混乱 | FC停止 | 出願前に権利者を決める（11-2 #4） |
| 共同オーナーとの認識齟齬 | 事業解消 | 8-4 の条項を文書化。**特に1階の賃貸借と、施術義務の非負担** |
| 稼働率が上がらない | 低 | 損益分岐12%（2.9枠）。**月3枠で黒字なので耐性は非常に高い** |
| 当日キャンセル | 中 | 事前決済＋キャンセルポリシー |
