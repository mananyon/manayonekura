## 1. エグゼクティブサマリー

### 1-1. 本企画書が答える問い

> **4,980円の店のオーナーが、同じ住所で28,000円の施術をどう成立させるか。**

これがWブランドの核心的な難問です。答えは3つです。

1. **オーナーは自分の店の価格では働かない。** 米倉さんの手は、ねここちの枠に入れてはいけません
2. **ねここちは"入口"、ここちめいどは"最上位"。** カニバリではなく、階段にする
3. **ねここちからの収入は"施術"ではなく"仕組み"で取る。** 監修料・人材供給・持分

### 1-2. 結論

| 項目 | 決定 |
|---|---|
| 東京での自分の商品 | **ここちめいど町田院 90分 28,000円**（初回120分 35,000円） |
| ねここちでの施術 | **原則ゼロ。**入らない。監修・教育・症例DBで関わる |
| 稼働 | 月3回の1泊2日遠征 ＝ **月6営業日 × 3枠 ＝ 月18枠** |
| 予約公開 | 完全紹介・LINE限定。**HPBには絶対に載せない** |
| ねここちからの対価 | **技術監修料（売上の3〜5%）＋ 人材供給フィー ＋ 持分配当** |
| 集客 | 広告ゼロ。**ねここち会員の中から、症状レベルの人を引き上げる（二段ファネル）** |
| 自由度の守り方 | **年間メンバーシップ（優先予約権）**で収入を稼働から切り離す |

### 1-3. 3事業＋ねここちが噛み合う構造 ★

これが今回いちばん重要な発見です。**4つの事業は、すでに完全な循環をつくれる位置にあります。**

```
        ┌─────────────────────────────────────────────┐
        │                                             │
        ▼                                             │
  ┌───────────┐   施術者を供給    ┌───────────┐         │
  │ ここちはり │ ───────────────▶ │  ねここち  │         │
  │  （育成）  │                  │（30分サブスク）│      │
  └───────────┘                  └───────────┘         │
        ▲                              │               │
        │ 認定院に紹介                  │ 症状レベルの   │
        │ （価格が合わない層）           │ 会員を引き上げ  │
        │                              ▼               │
  ┌───────────────────────────────────────────┐        │
  │        ここちめいど町田院（米倉まな本人）      │        │
  │            90分 28,000円 / 月18枠           │        │
  └───────────────────────────────────────────┘        │
        │                                             │
        │ 症例・エビデンス                              │
        ▼                                             │
  ┌───────────┐   「医学的根拠」というブランド価値       │
  │ 研究・学会  │ ────────────────────────────────────┘
  │  症例DB    │
  └───────────┘
```

| 流れ | 内容 | 価値 |
|---|---|---|
| ここちはり → ねここち | 受講生・認定院ネットワークが**業務委託鍼灸師の人材プール**になる | ねここちの最大のボトルネック（人材採用）が解決する |
| ねここち → ここちめいど | HPB広告で集めた会員のうち、**症状レベルの人を28,000円の枠へ引き上げる** | 米倉さんは広告費ゼロで月18枠を埋められる |
| ここちめいど → 研究 | 症例DB・学会発表・精神看護誌 | ねここちの「医学的根拠」を裏づける唯一の資産 |
| 研究 → ねここち | 「修士・学会発表・産学連携」の監修 | 無資格ヘッドスパ市場に対する**参入障壁**。FC販売の説得力 |

> **ねここちの真の差別化は「頭皮鍼」ではありません。**頭皮鍼は模倣されます。
> 模倣できないのは、**うつ・不安の実態調査を4報出し、精神神経学会でシンポジストを務める人が監修している**という事実です。
> だからこそ、その人の価値を安売りしてはいけません。

## 2. 「オーナーに見合う価格帯」— 数字で出す

### 2-1. 米倉まなの1時間はいくらか

| 働き方 | 時間 | 本人の取り分 | **時給換算** |
|---|---|---|---|
| ねここち 初回体験（業務委託50%） | 30分 | 2,490円 | 4,980円 |
| ねここち 月1回会員（同上） | 30分 | 2,750円 | 5,500円 |
| ねここち 都度利用（同上） | 30分 | 3,500円 | 7,000円 |
| 四日市 ここちめいど | 60分 | 14,000円 | 14,000円 |
| **ここちめいど町田院（提案）** | **90分** | **28,000円** | **18,667円** |
| **ねここち 技術監修（売上の5%）** | — | 73,000円／月 | **∞（施術時間ゼロ）** |

**米倉さんがねここちの枠に1時間入るごとに、約13,000円の機会損失が発生します。**
（18,667円 − 5,500円 ＝ 13,167円）

東京で使える時間は月45時間（6日 × 7.5時間）しかありません。

| 使い方 | 月収 |
|---|---|
| 全部ここちめいど（18枠 × 28,000円） | **504,000円** |
| 全部ねここち（90枠 × 5,500円 × 50%） | 247,500円 |

**同じ45時間で、2倍の差**が出ます。しかも前者は移動費を払っても黒字、後者はほぼ残りません。

### 2-2. だから、オーナーの手は店に入れない

これは効率の話だけではありません。**ブランドの話**です。

| もしオーナーが4,980円の枠に入ったら | 何が起きるか |
|---|---|
| 「米倉さんに30分5,500円で診てもらえる」 | 28,000円の枠が二度と売れなくなる |
| 「オーナーが現場を回している」 | 業務委託モデルへの信頼が落ちる（FC加盟希望者が引く） |
| 「オーナー指名が取れない」 | クレームの温床になる |
| 「米倉まな＝ヘッドスパの人」 | 学会・医科連携・メディアでの立ち位置が崩れる |

> **オーナーが自分の店の最低単価で働き始めた瞬間、その店の上限価格はオーナーの単価になります。**

### 2-3. 米倉さんの3つの役割（施術者ではない）

| 役割 | 内容 | 対価 |
|---|---|---|
| **技術監修者** | 頭皮鍼プロトコルの設計・施術マニュアル・安全基準・効果検証 | 技術監修料（3〜5%） |
| **人材供給元** | ここちはりの受講生・認定院から業務委託鍼灸師を供給・教育 | 人材供給フィー |
| **エビデンス責任者** | 症例データの蓄積・学会報告・「医学的根拠」の担保 | ブランド使用料に内包 |

**この3つは、すべて時間に比例しません。**だから店舗が増えるほど収入が増え、しかも東京に行く日数は増えません。
これが「自由度が高い働き方」の実体です。

## 3. ここちめいど町田院 — 価格設計

### 3-1. なぜ28,000円か

| 根拠 | 内容 |
|---|---|
| ① 時間が違う | 四日市60分 → 町田90分（傾聴の比重を上げる） |
| ② 出張費込み | 三重から往復。移動と宿泊の実費が乗っている |
| ③ 月18枠しかない | 希少性がそのまま価値 |
| ④ ねここちとの階段 | 4,980円 → 7,000円 → **28,000円**。中間を作らない（後述 4-3） |
| ⑤ 実績 | 修士／学会4報／産学連携／精神神経学会シンポジスト／のべ20,000人 |

> 東京の相場は自律神経・うつ対応で **60分5,500〜6,800円**。ねここちの都度7,000円はまさにこの相場帯です。
> **ここちめいどは、その市場に降りない。**別のカテゴリの商品です。

### 3-2. メニュー表

| メニュー | 時間 | 価格 | 内容 |
|---|---|---|---|
| 初回 | 120分 | **35,000円** | 問診・傾聴・施術・セルフケア指導・回復計画の設計 |
| 通常 | 90分 | **28,000円** | 傾聴＋施術 |
| 継続者短時間 | 60分 | **20,000円** | 状態が安定した方の維持（2回目以降のみ） |
| 3回券 | 90分×3 | **78,000円**（1回26,000円／6ヶ月有効） | |
| 6回券 | 90分×6 | **150,000円**（1回25,000円／12ヶ月有効） | |
| オンライン傾聴 | 60分 | **12,000円** | 来られない月のつなぎ |
| **年間メンバーシップ** | 12回／年 | **330,000円** | ★4-5 参照 |

### 3-3. 四日市の価格をどうするか

**据え置きを推奨します。**東京だけ上げる理由を明文化しておいてください。

> 「町田院は月に数日だけの出張診療です。移動・会場の費用を含み、傾聴の時間を厚くとった90分の設定にしています。四日市院の価格は変わりません。」

この一文を、LINE・サイト・受付に同じ文言で置いてください。表現がぶれると不信を招きます。

## 4. カニバリを防ぐ7つの分離ルール ★

**同じ住所で 4,980円 と 28,000円 を並べる**——これが本企画の最大のリスクです。
以下は「守れなければWブランドをやらない方がいい」レベルの必須ルールです。

| # | 分離する対象 | ルール |
|---|---|---|
| **1** | **商品カテゴリ** | ねここち＝**頭皮鍼30分のみ**。ここちめいど＝**全身＋傾聴90分**。メニューを重ねない。「短い版／長い版」に見せた瞬間に負ける |
| **2** | **対象者** | ねここち＝症状の**手前**（疲労・眠りの浅さ・肩こり）。ここちめいど＝**診断・自覚症状がある人**（うつ・不安・不眠症）。受付トークで明確に分ける |
| **3** | **施術者** | ねここち＝業務委託鍼灸師。ここちめいど＝**米倉まな本人のみ**。相互に入らない |
| **4** | **予約導線** | ねここち＝**HPB**。ここちめいど＝**LINE・紹介のみ、HPB非掲載**。ここが最重要 |
| **5** | **時間帯** | 米倉さんの滞在日は、ねここちの枠を午前に寄せ、**午後〜夜をここちめいど専有**（別室が2室あれば並行可） |
| **6** | **世界観** | ねここち＝明るい・軽い・通いやすい／ここちめいど＝生成りのベージュ・朱・明朝、静かで和の落ち着き（既存トーン維持） |
| **7** | **価格の見せ方** | **2つの価格表を同じ紙・同じ画面に並べない。**店頭・サイト・SNSすべてで別掲 |

### 4-1. 特に危険なパターン

| ❌ やってはいけない | なぜ |
|---|---|
| ねここちのメニューに「院長施術 60分 14,000円」を作る | 階段が壊れる。会員は必ず安い方を選ぶ |
| ここちめいどをHPBに載せる | HPBは価格比較の場。28,000円は必ず価格で負ける |
| ねここちで「初回体験→ここちめいど」を強く売り込む | 4,980円で来た人への高額提案はクレームになる。**引き上げは"相談"として行う**（8-3） |
| 中間価格帯（12,000〜18,000円）を作る | 上と下の両方から食われる。中間は空けておく |
| 米倉さんが「ヘルプで1枠だけ」ねここちに入る | 一度でも入ると前例になる。ゼロを貫く |

## 5. ねここち企画書への補足 — 投資家に指摘される点

共同オーナー・投資家向けの資料として、先に潰しておくべき論点です。**米倉さんの立場を守るためにも重要**です。

| # | 論点 | 現状の資料 | 指摘されること |
|---|---|---|---|
| **1** | **キャパと売上の不整合** | 稼働率60%＝月220回と記載。一方で売上シミュレーションは 月1会員150人＋月2会員50人＋都度20人 ＝ **月270回** | 270回には**稼働率77%**が必要。「保守的な60%」という説明と矛盾する。**売上を月220回ベース（約118万円）に修正するか、稼働率77%と明記すべき** |
| **2** | **解約率（チャーン）の想定がない** | 記載なし | サブスクで最重要の指標。月次解約率5%なら、150人維持に毎月7〜8人の新規が必要。**CACとチャーンをセットで示さないと投資判断ができない** |
| **3** | **会員転換率の想定がない** | 「カウンセリングで会員化」とあるのみ | 初回4,980円 → 会員化 何%か。**30%なら150人集めるのに500人の初回が必要**。HPB費用5万円/月で足りるか要検証 |
| **4** | **予約枠の集中** | 記載なし | 会員150人の希望は土日・平日夜に集中する。**1スタッフでは平日昼が空き、土日が取れない**構造になりやすい |
| **5** | **業務委託者の実働** | 月73万円の報酬 | 月270回 ÷ 22日 ＝ **1日12.3回の頭皮鍼**。実現可能だが消耗が大きく、離職リスクの説明が必要 |
| **6** | **家賃・内装・設備が未計上** | 「※家賃・消耗品費等は別途」 | 店舗利益68万円は家賃前の数字。**町田駅圏の家賃25〜40万を引くと 28〜43万**。ここを明示した方が誠実で、かえって信頼される |
| **7** | **鍼の廃棄・衛生・届出** | 記載なし | 医療廃棄物処理・施術所開設届。FC展開時は各店で必要。**加盟店支援メニューに含めると価値が上がる** |
| **8** | **偽装請負リスク** | 業務委託50% | シフト指定・時間拘束が強いと労働者性を問われる。**FC・多店舗前提なら契約書の整備が必須** |

> **1〜3を直すだけで、資料の説得力は大きく上がります。**
> そして、これらを整理できるのが「大学院で研究の作法を学んだオーナー」の価値です。ここは米倉さんの持ち場です。

## 6. 共同オーナーとの取り決め（提案）

米倉さんが持ち込む資産は、**現金でも労働でもなく、置き換えの効かない無形資産**です。ここを対価にしないと、施術で働くしかなくなります。

### 6-1. 持ち込む資産の棚卸し

| 資産 | 代替可能性 | 対価の形 |
|---|---|---|
| 頭皮鍼×自律神経の技術プロトコル | 低 | 技術監修料 |
| 「修士・学会4報・産学連携・精神神経学会シンポジスト」という肩書き | **不可** | ブランド使用料 |
| ここちはりの人材ネットワーク（施術者供給） | 低 | 人材供給フィー |
| 症例DB・エビデンス構築の能力 | **不可** | 監修料に内包 |
| のべ20,000人の臨床知見 | 低 | 監修料に内包 |
| 資本 | 高 | 出資持分 |

### 6-2. 対価の設計案

| 項目 | 提案 | 1店舗時 | 5店舗時 | 10店舗（FC含む） |
|---|---|---|---|---|
| **技術監修料** | 各店舗 売上の **3〜5%** | 44,000〜73,000円/月 | 219,000〜365,000円/月 | 438,000〜730,000円/月 |
| **人材供給フィー** | 業務委託鍼灸師 1名紹介・教育につき **200,000円** | — | — | — |
| **FCロイヤリティ分配** | 加盟金・ロイヤリティのうち監修相当分 | — | — | 別途 |
| **持分配当** | 出資比率に応じて | 別途 | 別途 | 別途 |

**10店舗になれば、監修料だけで月43〜73万円。**
これは**ここちめいど町田院を満席にした額（月35万円）を超えます。しかも東京にいる日数は増えません。**

### 6-3. 契約書に必ず入れる条項

- [ ] **商標**：「ねここち」「ここちめいど」「ここちはり」の**出願人・権利者を明記**（FC展開前に必須）
- [ ] **ブランド分離**：ここちめいどのブランド・患者情報はねここちに帰属しないこと
- [ ] **施術の非義務**：米倉さんはねここちで施術義務を負わないこと（★これを入れないと、いずれ「人が足りないから入って」となる）
- [ ] **監修料の算定基礎**：売上ベースか利益ベースか。直営とFCで別建て
- [ ] **離脱条項**：ブランド使用の停止条件と、その際の監修料の扱い
- [ ] **競業避止の範囲**：米倉さんが他院を監修することの可否
- [ ] **意思決定**：価格変更・出店・FC加盟承認の決定権をどちらが持つか

## 7. 稼働・収支

### 7-1. 遠征形態

## 8. マーケティング

### 8-1. 大方針：ここちめいどは広告を出さない

月18枠に広告は不要です。**広告はねここちの役割**です。

| | ねここち | ここちめいど町田院 |
|---|---|---|
| 集客 | HPB広告・SEO・口コミ | **紹介・LINE・既存資産のみ** |
| 広告費 | 月5万円〜 | **0円** |
| 露出 | 最大化 | **意図的に絞る** |
| 予約 | いつでも取れる | **月18枠・埋まったら終わり** |

> HPBは価格比較のプラットフォームです。28,000円をそこに置けば、必ず価格で負けます。
> **ここちめいどが売っているのは「安さ」でも「便利さ」でもなく、「この人に診てもらえること」です。**

### 8-2. 二段ファネル ★ これが最大の武器

```
 【ねここちが広告費を払って集める】
 HPB → 初回4,980円 → LINE登録 → 月額会員（5,500〜9,900円）
                                      │
                                      │ 会員の中に必ず一定数いる：
                                      │ ・眠れない日が続いている
                                      │ ・心療内科に通っている / 通うか迷っている
                                      │ ・30分では追いつかない状態
                                      │
                                      ▼  施術者が気づいて「相談」につなぐ
                        ┌──────────────────────────┐
                        │  ここちめいど町田院 相談枠  │
                        │  （米倉まな・30分・無料 or 5,000円）│
                        └──────────────────────────┘
                                      │
                                      ▼
                     ここちめいど 初回 120分 35,000円
```

**米倉さんは、広告費を1円も払わずに月18枠を埋められます。**
ねここちが月270回の接点を持つなら、そのうち**5%が症状レベル ＝ 月13.5人**。18枠を埋めるには十分です。

### 8-3. 引き上げの作法（ここを間違えると台無し）

| ✅ やる | ❌ やらない |
|---|---|
| 施術者が気づいて「一度、院長に相談してみませんか」と橋渡し | 受付やDMで高額メニューを提案する |
| **相談枠は施術ではなく"相談"**（30分・無料または5,000円） | いきなり35,000円を提示する |
| 「30分のケアでは追いつかない状態です」と**理由を言う** | 「もっと良いコースがあります」と言う |
| 引き上げなかった人には**そのままねここちを続けてもらう** | 会員を減らす方向に動く |
| 施術者に**紹介インセンティブ**（1件 5,000円など）を設定 | 施術者に成果ノルマを課す |

> **4,980円で来た人に、いきなり28,000円は出せません。**
> 間に「無料相談」を挟むこと。これが唯一、価格の階段を安全に登る方法です。
