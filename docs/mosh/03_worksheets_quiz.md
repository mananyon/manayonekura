# 声かけ例シート（A4 1枚・院内に置ける版）

**聴くときの3つの心がまえ**
すぐに解決しようとしない ／ 否定しない ／ 沈黙をこわがらない

**場面別のひとこと**

| 場面 | 声かけ例 |
|---|---|
| 様子が気になったとき | 「なんだかお疲れのように見えますが、最近どうですか？」 |
| 問診で | 「最近、眠れていますか？」「食事はとれていますか？」 |
| 話しはじめたとき | 「よかったら、聞かせてください」 |
| 話を受けとめる | 「〇〇なんですね」「それは、つらいですよね」 |
| もう少し聴きたいとき | 「そのとき、どんな気持ちでしたか？」 |
| 涙が出たとき | （ティッシュを渡して、急がずに待つ）「大丈夫ですよ、ゆっくりで」 |
| 話してくれたことに | 「話してくださって、ありがとうございます」 |
| 受診をすすめるとき | 「〇〇さんのことが心配なので、一度お医者さんにも相談してみませんか」 |
| 施術の終わりに | 「またいつでも、話したくなったら聞かせてくださいね」 |

**言わないようにしたいこと**
「がんばって」 ／ 「気にしすぎ」 ／ 「みんなそうですよ」 ／ 「私もそうでした」 ／ 「なんで？」

**「死にたい」と言われたら（TALK）**
心配だと伝える → はっきり聞く → 否定せず聴く → 一人にしない・つなぐ

# 確認クイズ

Googleフォームの「テスト」モードに入れると自動採点できます。
正解のあとに「解説」を表示する設定にしてください。

## 第1章 傾聴の土台

**Q1.** 患者さん「最近、仕事に行くのがつらくて…」。傾聴として一番よい返しは？
- A. 「転職を考えてみたらどうですか？」
- B. 「仕事に行くのが、つらいんですね」
- C. 「みんな同じですよ、がんばりましょう」
- D. 「どうしてつらいんですか？」

**正解：B** ／ 解説：くり返しと気持ちの反映。まずは受けとめることで、患者さんは「話してもいいんだ」と感じられます。Aはアドバイス、Cは励まし、Dは原因さがしで、話が止まりやすくなります。

**Q2.** 「無条件の肯定的関心（受容）」の説明として正しいものは？
- A. 患者さんの意見にすべて賛成すること
- B. 良い・悪いの評価をせずに、その人をそのまま受けとめること
- C. 患者さんを励まして前向きにすること
- D. 自分の意見をはっきり伝えること

**正解：B** ／ 解説：受容は「賛成」ではありません。評価をいったん横に置いて、その人がそう感じていることを受けとめる姿勢です。

**Q3.** 施術中、患者さんが黙ってしまいました。一番よい対応は？
- A. 気まずいので、すぐに別の話題をふる
- B. 「どうしました？」と何度も聞く
- C. あせらずに、少し待つ
- D. 施術に集中して、会話はやめる

**正解：C** ／ 解説：沈黙は、患者さんが気持ちを整理している大切な時間であることが多いです。待つことも技法のひとつです。

## 第2章 心の不調に気づく

**Q4.** 心の不調のサインに気づいたとき、セラピストの役割として正しいものは？
- A. うつ病かどうかを判断して、本人に伝える
- B. 気づいて、聴いて、必要なら専門家につなぐ
- C. 施術で治せるので、受診はすすめない
- D. 気づかないふりをする

**正解：B** ／ 解説：診断はセラピストの役割ではありません。身体に触れる私たちだからこそ気づけることを、つなぐ力にしましょう。

**Q5.** 次のうち、施術中に気づける心の不調のサインとして当てはまらないものは？
- A. 「どうせ」「自分なんて」という言葉が増える
- B. 予約のキャンセルが増える
- C. 施術のあと「すっきりした」と笑顔で帰る
- D. 眠れない、食欲がないと話す

**正解：C** ／ 解説：A・B・Dはいずれも気にかけたいサインです。

## 第3章 事例で学ぶ傾聴

**Q6.** 「夫と話がかみ合わない」という相談で、傾聴として大切なことは？
- A. 夫が悪いと一緒に怒ってあげる
- B. 夫の立場も考えるようにすすめる
- C. どちらの味方にもならず、患者さんの気持ちを聴く
- D. 夫婦カウンセリングを紹介して話を終える

**正解：C** ／ 解説：どちらかの味方になると、患者さんは本音を話しにくくなります。「〇〇さんは、そう感じているんですね」と気持ちに焦点をあてます。

**Q7.** 推し活の話のような楽しい雑談は、傾聴ではどう考えるとよい？
- A. 施術と関係ないので、早めに切り上げる
- B. 患者さんの大切にしているものや本音が見える、聴く時間になる
- C. 自分の好きなものの話をして盛り上げる
- D. 雑談は傾聴の対象ではない

**正解：B**

## 第4章 安全に関わるために

**Q8.** 患者さんが「もう消えてしまいたい」と言いました。最初の対応として適切なものは？
- A. 「そんなこと言わないで」と励ます
- B. 聞かなかったことにして、話題を変える
- C. 心配していることを伝え、死にたい気持ちがあるのかをはっきり聞く
- D. 「誰にも言わないから大丈夫」と約束する

**正解：C** ／ 解説：TALKの原則です。はっきり聞いても危険が高まるわけではありません。Dのような「秘密にする約束」は、つなぐことができなくなるので避けましょう。

**Q9.** 患者さんの話を深く聴いたあと、自分がとても疲れてしまいます。よい対応は？
- A. 聴くのをやめる
- B. 一人でがまんする
- C. 院のルールで境界線を決め、相談できる仲間を持つ
- D. 時間外もLINEで相談にのって、早く解決する

**正解：C** ／ 解説：長く寄り添い続けるためには、セラピスト自身を守ることも大切です。
